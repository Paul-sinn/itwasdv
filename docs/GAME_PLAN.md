## 1. 한 줄 컨셉

바탕화면 오른쪽 아래에 깔아두는 방치형 택배 게임. 배송으로 돈을 벌고, 정비소에서 트럭 엔진을 퍼질 각오로 튜닝한다.

| 항목 | 내용 |
|---|---|
| 장르 | 스팀 데스크톱 컴패니언(바탕화면에 띄워두는 게임) + 확률 강화 |
| 판타지 | 택배 기사로 취업 → 내 트럭 튜닝 → (출시 후) 회사 사장 |
| 엔진 | Godot |
| 플랫폼 | Windows 먼저 (Mac은 출시 후) |
| 판매 방식 | 스팀 한 번 구매. 인앱결제 없음 |
| 언어 | 한국어 + 영어 동시 출시 |
| 출시 | Next Fest 없이 최대한 빨리 (목표 2027년 2월 말~3월) |
| 가격 | $5.99 기준 + 출시 할인 10~15% |

## 3. 시장 리서치 요약

### 3.1 잘 된 게임들의 공통점
1. 한 줄로 설명되는 장치 ("화면 아래에 깔아두는 농장")
2. 귀여운 미니어처 그림, 작게 띄워놔도 그림처럼 보임
3. 진짜 방치: 신경 안 써도 진행됨
4. 싼 가격 ($4.99~$7.99에 몰려 있음)
5. 많은 언어 지원

### 3.2 안 된 게임들의 공통점 (리뷰 불만)
- "방치형인데 계속 클릭해야 함" (Desktop Heroes: 캐릭터가 죽으면 직접 살려야 함)
- "진행이 너무 느림" (Ropuka's Idle Island)
- "콘텐츠가 얇음, 돈 낼 가치 없음"
- "거래/돈벌이 냄새" (Desktop Wallet Heroes: 스팀 장터 거래 넣었다가 평가 바닥)

### 3.3 핵심 숫자
- **Rusty's Retirement** (1인 개발, $6.99): 첫 5일 10만 장, 2025년 7월 기준 약 55만 장 (개발자 본인 공개). 판매 비중 중국 26%, 일본 10%, 한국 6%, 대만 4% → 아시아 비중 큼
- **Cast n Chill** (2인, 호주): 리뷰 약 8,900개 중 95% 긍정. 매출 추정치는 사이트마다 2배 넘게 차이 남 (Raijin 약 $1.8M, Sensor Tower 약 $4.9M). 널리 퍼진 "$6.8M"은 근거가 약해서 계획에 쓰지 않음
- **Bongo Cat** (무료): 최고 동접 10만 명 이상인데 월 순수익 $2~4천 → 인기와 돈은 다른 문제
- 스팀이 2026년에 'Desktop Companion' 태그를 공식으로 만들었고, 2027년 1월 14~18일에 전용 축제가 열림

### 3.4 시장의 빈자리
- 데스크톱 컴패니언 쪽에서 **"택배 트럭 + 확률 강화"** 조합은 조사에서 하나도 못 찾음
- 가장 가까운 참고작: Pixel Car Racer (픽셀 차 튜닝, 모바일), Milky Way Idle (장비 강화형 방치), Idle Regenerator ("현금 없는 가챠"를 장점으로 홍보)
- 서양 메이플 유저는 "터짐을 없애달라"고 계속 요구해 옴. 단, 메이플 불만 대부분은 **현금**과 연결돼 있음 → 우리는 현금이 없다는 걸 스토어에 분명히 쓴다

## 4. 게임 구조

### 4.1 핵심 루프 [확정]
**배송으로 돈이 쌓임 → 정비소에서 튜닝(강화)·리맵에 씀 → 트럭이 세져서 더 큰 지역 배송을 땀 → 더 많이 범**

방치는 진짜 방치여야 한다. 사람 손이 가는 건 **튜닝 버튼 누를 때, NPC랑 놀 때, 능력치 찍을 때**뿐이다. 트럭이 멈춰서 사람이 눌러줘야 계속되는 구조는 절대 넣지 않는다.

### 4.2 진행 단계 [초안]

| 단계 | 내용 | 목표 시간 | 출시 버전 포함 |
|---|---|---|---|
| 1. 동네 | 트럭 1대, 집 몇 채, 물류센터. 튜닝 +0~+10 | 첫 1~3시간 | O |
| 2. 시내 | 배송지·도로 확장, 리맵 해금, 랜덤 이벤트, 창고 12시간 해금 | 3~15시간 | O |
| 3. 지역(도) | 장거리 배송, +15~+20, 퍼짐 구간 | 15~60시간 | 맛보기 1곳만 |
| 4. 회사 사장 | 보조 트럭, 노선 직접 설계 | — | 출시 후 |

- 첫 3시간 안에 "새로운 것"이 최소 10번 나와야 함 (새 집, 새 NPC, 새 부품, 첫 리맵, 첫 +10 등)
- **첫 30분 안에 튜닝(강화)을 맛보게** 한다. 테스트해 봤을 때 가장 재밌었던 부분이 이거다

### 4.3 건물 & NPC [확정 + 일부 초안]

| 건물/NPC | 하는 일 | 띠에서 누르면 |
|---|---|---|
| 물류센터 / 팀장 | 퀘스트, 주간 배송 목표(보험 쿠폰 지급) | 퀘스트 화면 |
| 카센터 / 사장 | 스페어 부품·스페어 엔진 파밍 | 부품 화면 |
| 튜닝숍 | 엔진 튜닝(강화), ECU 리맵 | 튜닝 화면 |
| 명장 (토요일 방문) | 보험 + 그 주 랜덤 보너스 | 토요일에만 등장 |
| 랜덤 전화 | 프랜차이즈 제안, 급한 VIP 배송, 사기 전화 등 | 알림으로 뜸 |

### 4.4 엔진 튜닝(강화)

**튜닝 확률표 [초안: 시뮬레이터로 반드시 검증]**

| 구간 | 성공 | 실패하면 | 퍼짐 |
|---|---|---|---|
| +0 → +10 | 95% → 55% | 단계 유지 | 없음 |
| +10 → +15 | 50% → 35% | 단계 유지 | 없음 |
| +15 → +18 | 33% → 30% | 1단계 하락 가능 | 없음 |
| +18 → +22 | 30% | 1단계 하락 | 2~5% |
| +22 → +25 | 10% → 3% | 1단계 하락 | 8~15% |
| +25 → +30 | 3% → 1% 이하 | 1단계 하락 | 15~20% |

**안전장치**
- [확정] 퍼지면 엔진이 고철이 되고, 스페어 엔진을 쓰면 **+15에서 재시작**
- [확정] 보험(퍼짐 방지): 명장 오는 토요일, 또는 보험 쿠폰 쓸 때만. 비용 추가
- [초안] 연속 하락 보정: 2번 연속 하락하면 다음 시도 100% 성공 (이름은 메이플 "찬스타임" 말고 새로 지을 것)
- [초안] 같은 단계에서 계속 실패하면 확률이 조금씩 오르는 누적 보너스
- [확정] 확률은 게임 안에 숫자로 전부 공개

**연출**: 버튼 → 1~2초 긴장(엔진 소리, 화면 흔들림) → 결과. 퍼질 땐 크게 "펑!" 하고 바로 "스페어 엔진 있음" 안내. 무섭지만 절망적이지 않게.

### 4.5 ECU 리맵 (큐브 대체) [초안]
- 부품에 붙는 랜덤 능력치(배송 속도 +%, 연비 +%, 팁 확률 +% 등)를 다시 굴리는 기능
- 위험 없는 도박 → "튜닝은 무섭고 리맵은 가볍게"로 감정의 리듬을 만듦
- 등급 이름은 메이플의 레어/에픽/유니크/레전드리를 쓰지 말고 차 문화로: 예) 순정 / 스트리트 / 스포츠 / 레이싱 / 프로토타입

### 4.6 명장 방문 데이 & 보험 쿠폰 [확정 구조, 보너스 목록은 초안]
- 매주 **토요일, 각자 현지 시간**. 명장이 오는 날은 보험이 항상 열림 + 랜덤 보너스 1개
- **금요일**에 명장이 전화로 예고: "내일 퍼짐 방지 부품 챙겨갈게"
- 보험 쿠폰: 주간 배송 목표 달성 시 1장, 아무 날이나 사용

**랜덤 보너스 후보 (매주 하나)**
- 퍼짐 확률 감소
- 튜닝 비용 할인
- 리맵 등급업 확률 상승
- 실패해도 단계 안 떨어짐
- 카센터 스페어 엔진 드랍 2배
- 리맵 비용 할인
- 성공하면 일정 확률로 2단계 상승

> 시계 조작: 혼자 하는 게임이고 리더보드가 없으면 그냥 허용. 남한테 피해 없음.

### 4.7 기사 레벨 & 능력치 [구조 확정, 목록은 초안]
- 배송 → 경험치 → 레벨업 → 능력치 포인트 투자
- **트럭과 역할을 나눈다**: 트럭 = 이동 속도·적재량 / 기사 = 사람 손이 가는 일
- 후보 (최종 4~5개 고르기):
  - 상하차 속도: 집 앞에 서 있는 시간 감소
  - 친절: 팁 확률·금액 증가
  - 협상: 배송 1건당 받는 돈 증가
  - 정비 지식: 카센터 스페어 부품 확률 증가
  - 길 숙련: 배송 동선 효율 증가

### 4.8 오프라인 진행 [확정]
- 꺼둔 동안 들어온 택배가 **물류센터 창고**에 쌓이는 개념. 창고가 차면 더 안 쌓임
- 창고 확장(쌓이는 시간): 4 → 6 → 8 → 12시간 (12시간은 시내 단계부터, 24시간은 회사 사장 업데이트 때)
- 야간 배송팀(꺼둔 동안 버는 속도): 50 → 60 → 70 → 80%. **최대 80%**

### 4.9 랜덤 전화 이벤트 [초안]
- 5~15분에 1번. 알림은 **작게** (방해되면 안 됨)
- 출시 버전 5~8종: 프랜차이즈 제안, 급한 VIP 배송, 사기 전화(거절하면 보상), 명장 예고 전화 등

### 4.10 돈이 빠지는 곳
튜닝 비용(단계마다 급증), 리맵 비용, 보험 비용, 창고 확장, 야간 배송팀, 새 지역 개척비, 차 꾸미기 부품, 기름값·정비비(아주 작게)

### 4.11 경제 시뮬레이터 목표 [확정]

| 유저 유형 | 하루 켜두는 시간 | 30일 후 목표 |
|---|---|---|
| 가볍게 하는 유저 | 2~3시간 | +18 (퍼짐 구간 입문) |
| 열심히 하는 유저 | 8시간 이상 | +20 |

+18과 +20은 2강 차이지만, +18부터는 성공률 30%에 퍼짐까지 있어서 실제로 드는 노력은 몇 배 차이 난다.

## 5. 메이플 차별화 [확정]

**원칙: 확률·강화 구조는 벤치마킹 유지, 이름과 화면은 전부 차 튜닝 문화로.**

| 메이플 | 우리 게임 |
|---|---|
| 스타포스 / 별 | 튜닝 스테이지 (실제 튜닝 용어 "스테이지 1, 2"). 별 대신 계기판 바늘·RPM 게이지·STAGE 숫자 |
| 파괴 | 엔진 퍼짐 |
| 큐브 / 잠재능력 | ECU 리맵 |
| 레어/에픽/유니크/레전드리 | 순정/스트리트/스포츠/레이싱/프로토타입 (예시) |
| 썬데이 메이플 | 토요일 명장 방문 |
| 찬스타임 | 새 이름 필요 |
| 스타포스 강화 창 | 정비소 리프트에 차 올려놓고 작업하는 장면 |

- 지금 프로토타입의 ★ 표시도 바꾸는 걸 추천
- 스토어, 홍보물 어디에도 "메이플" 이름은 쓰지 않음. 한국에서는 "강화 좋아하는 사람을 위한 게임"으로 홍보

**법적 참고 (변호사 아님, 출시 전 확인 권장)**
- 게임 규칙 자체는 원래 아이디어로 봐서 저작권 보호가 약하다
- 하지만 2019년 대법원(킹닷컴 대 아보카도)은 여러 요소의 조합이 다른 게임과 구별되는 개성을 가지면 저작물로 보호된다고 봤다
- 엔씨 대 웹젠 R2M (2025년 3월 2심): 저작권 침해는 인정 안 했지만 부정경쟁으로 서비스 중단 + 169억 원 배상. 같은 판결에서 장비 강화 체계 같은 개별 요소는 아이디어 수준이라 보호 대상이 아니라고 봤다. 반면 아이콘·상점 그래픽을 바꾼 정도는 소용없다고 봤다
- **결론: 시스템 하나하나는 써도 된다. 위험한 건 이름, 화면 배치, 시스템 조합을 통째로 따라 하는 것**

## 6. 화면 & 아트

### 6.1 두 가지 모드 [확정]
- **띠 모드**: 바탕화면 오른쪽 아래, 작업표시줄 위에 작게. 백그라운드에서 돌아감
- **정비소 화면**: 띠를 누르면 설정에 따라 창 모드 또는 전체 화면. Cast n Chill 같은 UI에 NPC가 있음

### 6.2 띠 모드 조작 [확정]
- 누를 수 있는 것: **건물 + 작은 버튼 하나**. 트럭은 안 됨
- 건물에 마우스 올리면 살짝 빛남 + 이름표 → 누를 수 있다는 걸 알게 함
- 건물 누르면 그 건물 화면으로 바로 이동 (4.3 표 참고). 작은 버튼은 메인 화면
- 나머지 영역은 클릭이 뒤의 바탕화면으로 통과

### 6.3 그림 방향 [방향 확정, 숫자는 초안]
- 배경·NPC: Cast n Chill 같은 아늑한 픽셀 아트. 아침→저녁→밤 빛 변화, 비 오는 날, 골목 고양이 같은 "보기만 해도 좋은" 요소를 일찍 넣는다
- 차: 픽셀 아트 유지하되 **해상도를 크게**. 차가 주인공이니까 제일 디테일하게
- 한 화면 안에서 픽셀 크기를 섞지 않는다 → 모드별로 따로 그림

| 모드 | 화면 | 트럭 크기 |
|---|---|---|
| 띠 모드 | 높이 약 100~150px | 가로 약 32~48px (실루엣·색만 보이면 됨) |
| 정비소 화면 | 창/전체 화면 | 가로 약 160~256px (휠·스포일러·데칼 보임) |

- **같은 부품을 두 크기로** 따로 그림 (큰 걸 줄이면 뭉개짐)
- 부품 레이어 순서 고정: 바퀴 → 차체 → 도색 → 데칼 → 스포일러·액세서리 → 튜닝 이펙트
- 도색은 회색조 차체 + 색만 바꾸기(팔레트 교체)
- 튜닝 단계가 눈에 보이게: +10, +15, +20, +25에서 배기 불꽃·오라·반짝이 등. 띠 모드에서도 "저 트럭 +20이네"가 보여야 자랑할 맛이 남
- 참고작: Pixel Car Racer (픽셀로도 차 튜닝이 멋있어 보일 수 있다는 증거)

### 6.4 AI 그림 사용 [확정: AI 사용]
- **스팀 규칙 (2026년 1월 개정)**: 게임 안에 들어가는 AI 그림·소리·글, **스토어 이미지·홍보물**은 반드시 표시. 코딩 보조(Claude로 코드 짜기)는 표시 대상 아님
- 일관성 관리 (AI 픽셀 아트의 흔한 문제: 픽셀 크기 들쭉날쭉, 팔레트 변화, 비율 흔들림):
  - 고정 팔레트(예: 32색), 고정 격자에 맞춰 후처리
  - **차 템플릿 1개(측면, 고정 크기)를 가장 먼저 확정**하고 모든 부품을 그 위에 맞춤
  - 애니메이션은 2~4프레임짜리 단순 반복이 안정적
- 참고 데이터: AI 사용을 표시한 게임은 리뷰 수가 적고 긍정률도 낮은 경향이 있음. 반발이 가장 큰 곳은 **스토어 대표 이미지(캡슐)** → 캡슐 제작 방식은 게임 완성 후 다시 결정

## 7. 기술 구조 (Godot, 큰 그림)

- **창 설정**: 테두리 없음, 투명, 픽셀 단위 투명 켜기. 렌더링 투명 배경도 켜기
- **클릭 통과**: 창의 클릭 영역 지정 기능(mouse_passthrough_polygon)으로 건물 + 버튼만 클릭 받기
- **위치**: 작업표시줄을 뺀 사용 가능 영역(screen_get_usable_rect) 맨 아래에 띠 배치. 저장된 모니터가 없어지면 주 모니터로 복귀
- **모드 전환**: 창 하나로 크기·테두리·투명 여부를 바꿔 정비소 화면으로. 경제 데이터는 화면과 분리된 관리자 객체(싱글톤)에 둬서 화면이 바뀌어도 숫자가 안 꼬이게
- **가벼움 (장르 필수 조건)**: 띠 모드에서 저전력 모드 + 10~30fps 제한. 경제 계산은 1초에 1번
- **저장**: user:// 폴더에 JSON + 마지막 종료 시각. 30~60초마다 자동 저장 + **튜닝 버튼 누른 직후 저장** (퍼지면 강제 종료하는 꼼수 방지)
- **스팀**: GodotSteam으로 업적·클라우드 저장. 리더보드는 출시 후 (혼자 하는 게임이라 조작 막기 어려움)
- **데이터 파일로 관리할 것**: 부품, 확률표, 이벤트 보너스 목록, 전화 이벤트, 능력치 → 밸런스 조정 쉽고 후원자 팩 대비
- **1주차 기술 검증 (필수)**: Windows에서 투명 + 클릭 통과 창을 오래 켜두면 화면이 어두워지거나 작업표시줄이 깨진다는 보고가 있음
  - 24시간 켜두기 테스트 (Windows 10, 11)
  - 멀티 모니터, 작업표시줄 위치 바꾸기, 화면 배율 바꾸기

  - 틱톡 / 인스타 릴스 / 유튜브 쇼츠: Rusty 개발자가 실제로 효과 본 채널

  - 스트리머: 한국은 메이플·방치형 다루는 스트리머 (치지직, SOOP, 유튜브), 글로벌은 코지·방치 유튜버. 데스크톱 컴패니언은 방송 화면 구석에 띄우기 좋음

- **문구**
  - 영어: "No microtransactions. Pure, risky, fair tuning." (현질 없음, 위험하지만 공정한 튜닝)
  - 한국어: "강화 좋아하는 사람을 위한 게임" (메이플 이름은 안 씀)
- **가격**: 미국 $5.99, 다른 나라는 스팀 추천 지역 가격. 출시 할인 10~15%
- **언어 추가 우선순위**: 중국어 간체 → 일본어 (Rusty 판매의 26%가 중국, Cast n Chill은 일본 SNS에서 먼저 터짐)
- 스팀 장터 거래, 카드 드랍 같은 돈벌이 요소는 넣지 않음 (봇 몰림 + 평판 하락)

## 10. 출시 버전 범위 (MVP = 이것만)

1. 띠 모드: 동네 순환 도로, 집, 물류센터, 트럭 1대, 돈 표시
2. 건물 클릭 + 작은 버튼 → 정비소 화면 (창/전체 화면)
3. 엔진 튜닝 +0~+30: 확률 공개, +18부터 퍼짐, 스페어 엔진(+15 복구), 연속 하락 보정
4. ECU 리맵: 부품 3종(엔진/타이어/적재함)
5. NPC: 카센터 사장, 튜닝숍, 물류센터 팀장, 토요일 명장
6. 토요일 명장 방문 (보험 + 랜덤 보너스) + 금요일 예고 전화 + 보험 쿠폰
7. 기사 레벨 + 능력치 4~5개
8. 지역: 동네 → 시내 (+ 지역 1곳 맛보기)
9. 창고 확장(4~12시간) + 야간 배송팀(50~80%)
10. 차 꾸미기: 도색 8색, 휠 4종, 스포일러 3종, 데칼 5종, 튜닝 단계 이펙트
11. 랜덤 전화 이벤트 5~8종
12. 설정: 소리, 알림, 띠 높이·위치, 투명도, 모니터 선택
13. 스팀 업적 15~25개, 클라우드 저장
14. 한국어 + 영어
