## 0. 설계 원칙 [확정]

1. **운은 좋아지는 쪽으로만, 손해는 없게.** 서양 유저는 운 자체보다 "운 때문에 손해 보는 것"을 싫어한다. 일부러 남긴 손해는 엔진 퍼짐 하나뿐이고(강화 실패는 단계 유지), 그건 스페어 엔진·보험·천장으로 받쳐준다.
2. **나중 업데이트로는 좋은 것만 추가한다.** 세금처럼 빼앗는 건 처음부터 넣고, 업데이트는 늘 반가운 소식이 되게 한다 (예: 세무사 NPC로 세금 감소).
3. **방치는 진짜 방치.** 사람 손이 가는 건 강화·세팅 버튼, NPC, 능력치, 경영 결정뿐. 트럭이 멈춰서 눌러줘야 하는 구조는 없다.
4. **켜두는 게 항상 이득.** 꺼둔 동안은 버는 속도가 최대 80%, 경험치는 기본 0 (능력치 '노하우'로 최대 50%).
5. **초반엔 돈이 빡세고, 후반엔 돈이 넘쳐서 고강화에 도전하게.**
6. **메이플 구조는 벤치마킹하되 이름과 화면은 차 튜닝 문화로.** (5장)
7. **초반 2시간은 빠르게, 그 뒤는 몇 달 갈 만큼 천천히.** 늘 켜두는 서브 게임이라 후반은 길수록 좋다. 스팀 환불 기준(플레이 2시간) 안에 첫 배달·첫 강화·첫 세팅이 나와야 함

## 4. 게임 구조

### 4.1 핵심 루프 [확정]
**배송으로 돈이 쌓임 → 엔진 강화·세팅으로 트럭이 세짐 → 출력 제한 배송·큰 계약을 땀 → 트럭·직원을 늘려 회사를 키움 → 더 많이 범**

### 4.2 회사 단계 [확정] — 숫자는 시트 "회사 단계"
| 단계 | 무대 | 출시 버전 |
|---|---|---|
| 개인 기사 | 동네 | 포함 |
| 대리점 | 시내 (단가↑, 집·회사 건물 늘어나 자주 멈춤, 도시 배경) | 포함 (목표: 시내 1위) |
| 지역 택배사 | 지역 | 업데이트 |
| 전국 택배사 | 전국 | 업데이트 |
| 글로벌 | 해외 | 업데이트 (최종 목표: 세계 1위) |

- **라이벌 순위표:** 가상의 택배회사 10개와 매출로 경쟁. 실제 회사 이름(UPS 등)은 상표 문제로 안 씀
- 순위표는 처음부터 세계 순위까지 다 보이고, 위쪽은 잠겨 있음 → "언젠가 저기까지"가 보이게
- 대리점 창업은 중반의 큰 목표: "강화에 지를까, 창업 자금 모을까" 고민하게
- **[확정] 시내가 동네와 다른 점:** 배송 단가가 오르고, 배송할 집과 회사 건물이 늘어나 집 간격이 촘촘함 → 운전은 짧고 자주 멈춤 → 상하차 능력치가 빛남. 배경 그림도 도시로 (띠 모드 포함) 바뀌어서 창업한 게 눈에 보임. 레벨이 어느 정도 오른 시점이라 상하차에 포인트를 더 줄지가 유저 성향에 따라 갈림
- **노선 세 가지의 성격:** 동네 = 중간, 시내 = 멈춤 많음(상하차), 장거리 = 운전 많음(속도·터보). 대리점부터 트럭마다 [시내 / 장거리] 노선을 고름
- **[확정] 출시 버전의 끝:** 시내 1위 대리점 달성 → 축하 연출 + "다음 업데이트에서 지역 진출" 안내 → 그 뒤로도 강화·세팅·트럭 키우기 계속. 환생(처음부터 다시) 시스템은 안 넣음
- **[확정] 끝까지 목표 시간:** 시내 1위까지 가볍게 10~12주, 열심히 6~8주
- **[확정] 순위 기준:** 켜둔 상태의 시간당 매출. 다음 순위까지 얼마 남았는지 보여줌. 라이벌 숫자는 고정값
- 대리점 단계에 장거리 노선 1개를 열어서 터보 쓸 곳을 만든다 (장거리 = 대리점 + 엔진 +10)
- 첫 30분 안에 강화를 맛보게 하고, 첫 3시간 안에 "새로운 것"이 10번 이상 나오게 한다

### 4.3 건물 & NPC
| 건물/NPC | 하는 일 |
|---|---|
| 물류센터 / 팀장 | 퀘스트('다음 할 일' 목록), 주간 배송 목표(돈 + 경험치), 물류센터 업그레이드(동네) |
| 카센터 / 사장 | 스페어 엔진 파밍(배송하다 가끔 드랍, 가볍게 기준 약 2주에 1개) + 스페어 엔진 판매 |
| 튜닝숍 | 엔진 강화, 세팅 돌리기 |
| 랩핑샵 | 외형(랩핑) 구매·변경 |
| 명장 (유저가 고른 요일) | 그 주 랜덤 강화 보너스 (하루 동안) |
| 보험사 (3~4주에 한 번 랜덤) | 하루 머물며 보험 판매 + 방문 이벤트 1개 |
| 마술사 (3~4주에 한 번 랜덤) | 하루 동안 큐브 등급업 확률 2배 |
| 중고 부품상 (3~4주에 한 번 랜덤) | 고급 스페어 엔진 1개 선물 (+17에서 재시작) |
| 랜덤 전화 | 급송 전화, 명장 예고 (업데이트: 프랜차이즈 제안, 사기 전화) |
| 대리점 사무실 (대리점 단계) | 보조 트럭·직원 관리, 기업 계약, 순위표 |

### 4.4 엔진 강화 — 숫자는 시트 "강화 단계"
- **강화 = 고정 수치, 세팅 = 퍼센트** (메이플 스타포스 = STR 고정값, 잠재능력 = STR %와 같은 구조). 강화가 높을수록 세팅 % 효과도 커져서 두 시스템이 서로 키워준다
- 엔진 출력이 곧 기본 이동 속도. 퍼짐이 시작되는 +18 근처부터 출력 상승폭이 크게 뜀 → "터질 수 있어도 누를 가치"
- **출력 제한 배송** (메이플 스타포스 제한 지역처럼): +10 장거리 노선, +15 대형 화물, +18 VIP 귀중품. 강화가 숫자 놀이가 아니라 "새 콘텐츠를 여는 열쇠". **[확정]** 지금 단계 기준이라 퍼져서 +15가 되면 VIP가 다시 잠김. 장거리는 대리점이어야 열림
- [확정] **강화 실패 시 하락 없음:** 실패하면 단계 그대로. 위험은 +18부터 퍼짐 하나뿐 (원칙 1). 예전 시트 초안의 "+15부터 1단계 하락"은 확정한 적 없는 값이라 지움
- [확정] 연속 실패 보호 없음: 얻기 힘든 만큼 값지게. 안전장치는 스페어 엔진(+15 복구), 보험(보험사 방문 날), 고급 스페어 엔진(부품상), ECU 엔진 보호, 명장 보너스(강화 성공 확률 상승 등)로 충분
- 시뮬레이터에서 "운 나쁜 하위 10% 유저"도 확인: 이 사람들이 너무 일찍 접지 않는 수준인지
- 연출: 버튼 → 1~2초 긴장 → 결과. 퍼질 땐 "펑!" + 바로 "스페어 엔진 있음" 안내
- **퍼짐의 아픔은 스페어 값이 아니라 +15에서 다시 올라가는 비용.** 시뮬레이터 지표: "퍼진 뒤 원래 단계로 돌아가는 데 며칠치 수입이 드는가"가 후반까지 일정하게 아프면 성공

### 4.5 세팅 돌리기 — 숫자는 시트 "세팅 규칙", "세팅 등급업", "세팅 옵션 수치", "출시 4개", "추가 후보"
**출시 부품 4개: 역할을 "많이, 빠르게, 아끼게, 멀리"로 나눔**
| 부품 | 역할 | 열리는 시점 |
|---|---|---|
| 적재함 | 많이 | 동네 (처음부터) |
| ECU | 빠르게 | 엔진 +5 (동네 후반) |
| 타이어·휠 | 아끼게 | 대리점 창업 (= 시내) |
| 터보 | 멀리 | 대리점 + 엔진 +10 (장거리 노선) |

**옵션 세 종류**
- **공용 (끝판 목표):** 이동 속도 %, 기름값 절감 %. 어느 부품에 붙어도 현실적으로 말이 되는 것만. 속도 빌드면 "이동 속도 3줄"이 끝판왕
- **옵션 한 줄의 가치 맞추기:** 모든 옵션이 이동 속도 한 줄의 절반~비슷한 수입 효과가 나게. 그래서 기름값 절감은 수치 5배(10~60%) + 기름값 비율을 단가의 20%로, 오버부스트는 "그 바퀴 전체 2배" + 확률 3배. 엔진 보호는 돈이 아니라 퍼짐을 막는 거라 예외
- 적재량처럼 개수로 바뀌는 효과는 소수점을 확률로 (1.6건 → 60% 확률로 2건)
- 이동 속도 뽑힐 가중치는 다른 옵션보다 낮게 두되, 3줄이 "사실상 불가능"은 아니게 (평균 약 730번)
- **전용:** 적재함 = 적재량, 터보 = 장거리 속도, 타이어 = 정비비 감소, ECU = 엔진 보호·오버부스트. 공용보다 수치가 높아서 "공용 3줄이냐, 센 전용을 섞느냐" 고민이 생김
- **잡옵:** 승차감, 방향제, 컵홀더, 라디오 수신 감도, 외관 광택. 효과 없음. 원하는 3줄을 어렵게 + "컵홀더 3줄 ㅋㅋ" 쇼츠 짤

**규칙**
- 메모리얼 있음, 줄 잠금 없음, 등급 하락 없음
- 천장 카운터를 화면에 표시 ("천장 312/500")
- 줄어드는 옵션은 각자 최대 60% (기름값 절감 60%, 정비비 감소 60% 따로), 엔진 보호는 3줄이어도 최대 30%
- 전용 옵션(적재량 등)은 공용보다 세게: 이동 속도 한 줄의 약 1.3배 목표
- 마술사가 온 날 하루 동안 세팅 등급업 확률 2배 (기사 능력치 "운"은 뺐으니 등급업 확률을 올리는 건 이것뿐)
- [확정] 모든 줄이 지금 등급 수치로 뜸 (2·3번째 줄이 낮은 등급으로 나오는 메이플 방식은 안 씀. 표 절반, 설명 쉬움)
- 순정 → 프로토타입은 부품 하나당 평균 약 312번 (그중 83%가 마지막 단계). 실제 일수는 1회 비용과 수입이 정해져야 나옴

**외형**
- 등급 오르면 부품 모양·효과가 바뀜 (휠 디자인, 차 높이, 적재함 장식, 터보 = 배기 불꽃, ECU = 헤드라이트 색)
- 외형 고정 옵션: 성능은 새 등급, 모양은 예전 걸로

### 4.6 랩핑샵 [확정]
- 차체 색·무늬만 바꿈 (등급 외형이랑 안 겹침). 성능 없음
- 게임 돈으로 구매 + 업적·이벤트 보상. 뽑기 없음
- 출시 4개 (구매용 2 + 보상용 2). 나머지는 업데이트
- 보상 예시: 첫 +18 성공, 첫 엔진 퍼짐 "위로" 랩핑, 명장 방문 N회
- 나중에: 후원자 팩 스킨, 회사 사장 업데이트 때 "내 회사 로고 랩핑"

### 4.7 이벤트 [확정 2026-11-14, 하나씩 정함] — 숫자는 시트 "이벤트"

| 이벤트 | 언제 | 하는 일 |
|---|---|---|
| 명장 | 매주, 유저가 고른 요일 하루. 전날 예고 전화 | 강화 버프 1개 랜덤: 퍼짐 확률 30% 감소 / 강화 성공 확률 1.2배 / 성공 시 10% 확률로 한 단계 더 |
| 보험사 | 3~4주에 한 번 랜덤, 하루 | "오늘 보험 가입?" [예/아니오] + 이벤트 1개 랜덤: 제휴 할인 / 복구 보험 |
| 마술사 | 3~4주에 한 번 랜덤, 하루 | 큐브(세팅 돌리기) 등급업 확률 2배 |
| 중고 부품상 | 3~4주에 한 번 랜덤, 하루 | 고급 스페어 엔진 1개 선물 (+17에서 재시작) |
| 급송 전화 | 30~60분마다 | 띠의 전화 아이콘을 5분 안에 누르면 다음 50건 단가 2배 |
| 주간 배송 목표 | 매주 | 6만 건 채우면 돈 보너스(하루치 수입) + 경험치 |

#### 알림과 대화
- 이벤트 NPC가 오면 오른쪽 위에 **편지봉투 아이콘 + 느낌표**. 띠 모드에서 누르면 큰 화면(전체화면/창)으로 바뀌고 NPC가 튀어나옴
- 명장·마술사·부품상: 대사 한 번, 효과는 자동 (봉투를 안 눌러도 그날 효과·선물이 들어감)
- 보험사: 돈이 걸린 일이라 [예/아니오]. 눌러서 "예"를 해야 보험 가입
- 급송 전화는 편지봉투가 아니라 **전화 아이콘**. 누르면 큰 화면 안 열고 바로 받음

#### NPC 규칙
- 하루에 NPC 한 명만. 명장 요일엔 다른 NPC가 안 옴. 날짜가 겹치면 다음 날로 미룸 (고르게 퍼지게)
- 하루(24시간) 머묾. 게임이 꺼져 있었으면 그 하루 안에 켰을 때 와 있음
- 보험사·마술사·부품상이 각자 3~4주에 한 번이라 합치면 대략 1~2주에 한 번 특별 NPC (매주 명장 + 가끔 특별 NPC)

#### 명장 방문일 (강화 버프 날)
- **이벤트의 목적:** 버는 족족 써버리면 기대만큼 성장을 못 느끼고 질림 → 돈을 모아뒀다가 그날 한 방에 지르게 만드는 장치
- **요일은 유저가 직접 고름.** 처음 해금될 때 "어떤 요일에 명장이 오면 좋겠어요?"라고 물어봄. 바꾸면 다음 주부터 적용
- 고른 요일에 게임을 안 켜면 그 주는 놓침 (자기가 고른 날이라 공평)
- 보너스 3개 중 1개 랜덤, 방문일 하루 동안만. 전날 전화로 예고. 명장 날엔 보험 없음
- 강화 화면에 "지금 모은 돈이면 몇 번 시도 가능"을 보여줘서 모으는 재미가 눈에 보이게
- 검토했다가 안 쓴 안: 토요일 고정(주말에 PC 안 하는 사람 손해), 토요일 + 놓치면 다음 실행 때(토요일 의미 없어짐), 주 1회 호출권
- 시계 조작: 혼자 하는 게임이라 허용
- 명장에서 뺀 것: 큐브 비용 할인(아예 뺌), 강화 비용 할인(→ 보험사 제휴 할인), 큐브 등급업(→ 마술사), 스페어 드랍 2배(→ 부품상 고급 스페어. 하루 2배는 0.1개도 안 돼서 티가 안 남)

#### 보험 & 보험사
- **보험:** 강화 한 번에 거는 것. 그 한 번은 퍼짐이 나와도 안 퍼지고 실패(단계 유지)로 끝남. 성공·실패 확률은 안 바뀜. +17 이하는 원래 안 퍼져서 안 걸림
- **보험은 보험사가 온 날에만** (보험 쿠폰은 뺌). 그래서 보험사 오는 날이 특별함
- 보험사가 오면 "오늘 보험 가입하시겠어요?" [예/아니오]. **예면 그날 +18 이상 강화할 때마다 보험료가 자동으로 같이 나감**
- **보험료 = 그 회 강화 비용 × 그 단계 퍼짐 확률 × 10** (강화 1번마다). +18은 강화비의 0.2배, +22는 0.8배, +29는 2배. 평균 손해보다 조금 비싼 정도 (진짜 보험처럼). 고강일수록 점점 이득
  - 예: +20 → +21 (강화비 1억, 퍼짐 4%) → 보험료 4천만, 총 1억 4천
- 방문마다 이벤트 1개 랜덤:
  - **제휴 할인:** 그날 가입한 사람은 강화비 반값 (보험료는 원래 강화비 기준). 예: 5천만 + 4천만 = 9천만 → 보험 없이 하는 것(1억)보다 싸서 그날은 가입하고 지르는 날
  - **복구 보험:** 그날 가입 안 하고 퍼져도 +15 대신 +17에서 재시작. 보험료 아끼고 운에 맡기는 사람의 날
- 바뀐 이유: 예전엔 명장 날에 보험(강화비 2배)을 붙였는데 평균 손해의 3~22배라 쓰면 손해였음. 명장은 버프 날, 보험은 보험사로 분리
- 뺀 것: 보험 쿠폰, 단체 보험, 보험료 반값, 실패 환급(둘 다 결국 할인이라 제휴 할인으로 합침)

#### 마술사
- 그날 하루 큐브 등급업 확률 2배 (레이싱 → 프로토타입 0.3% → 0.6%). 천장 카운터는 그대로 쌓임. 1.5배는 시뮬에서 "거의 꽝"이었음
- 명장 날 = 엔진 강화 지르는 날, 마술사 날 = 큐브 지르는 날

#### 중고 부품상
- 고급 스페어 엔진 1개 선물. 끼우면 +15 대신 +17에서 재시작. 보관했다가 아무 때나 씀 (보험사 복구 보험은 그날만이라 안 겹침)

#### 급송 전화
- 30~60분마다. 띠에 전화 아이콘, 5분 안에 누르면 바로 받음 (30초는 일하면서 켜두는 게임엔 너무 짧았음)
- 내 트럭 다음 50건 단가 2배. 대형·VIP가 섞이면 배수를 곱함 (VIP 급송 = 10배 대박)

#### 주간 배송 목표
- 매주 6만 건 (꺼둔 동안 배송 포함). 채우면 돈 보너스(그 시점 하루치 수입) + 경험치 2,000. 명장 날 지를 돈에 보태지는 흐름

### 4.8 기사 레벨 & 능력치 — 숫자는 시트 "경험치 얻는 법", "레벨 곡선", "기사 능력치"
- **기사 능력치의 역할: 초반 힘든 구간을 넘기게 도와주는 것.** 그래서 만렙을 빨리 찍게 한다
- 만렙 50, 목표 가볍게 하는 유저 2주(켜둔 약 35시간). 경험치는 켜둔 시간에 비례해서 열심히 하는 유저는 약 4~5일 (1주·2주를 둘 다 맞출 수는 없음)
- 꺼둔 동안 경험치는 기본 0. 능력치 '노하우'로 켜둔 것의 최대 50%까지 (오래 켜둘 수 없는 유저를 위한 능력치. 50% 상한이라 켜두는 게 여전히 이득)
- **만렙 후 경험치 → 회사 평판** (평판이 쌓이면 큰 계약 제안)
- 트럭 = 이동 속도·적재량, 기사 = 사람 손이 가는 일. 같은 효과는 한쪽으로만
- **[확정] 적용 범위:** 능력치·경험치는 내 트럭에만 (협상은 기업 계약 금액에도). 친절은 기본 팁 확률(0보다 큼)에 더함. 노하우 경험치도 창고 상한 시간까지만
- **출시 5개 (압도되지 않게 5개가 상한), 처음부터 전부 열림 → 여러 빌드로 갈 자유도:**
  - 상하차 속도(물류센터에서 싣는 시간 + 집 앞 정차 시간 감소), 친절(팁 확률), 협상(단가 + 기업 계약 금액): 초반 돈·속도 병목 해결. 상하차는 자주 멈추는 시내에서 특히 빛남
  - 친절은 보너스 능력치: 팁 금액이 배송 단가에 비례해서, 협상을 올리면 팁도 같이 커짐 (돈벌이 빌드 = 협상 + 친절 시너지)
  - 노하우: 꺼둔 동안 경험치. 만렙 후엔 회사 평판으로 쌓여서 계속 쓸모 있음. 최대면 가볍게 유저 만렙 약 7일 (그대로 두기로 함. 초기화가 무료라 만렙 전 몰빵 → 만렙 후 초기화도 받아들임)
  - 정비 지식: 카센터 스페어 엔진 드랍 확률 최대 2배 (강화 빌드용)
- **밸런스 기준:** 능력치마다 최대로 찍었을 때 "수입 몇 % 오르는 것과 같은지"로 환산해서 다섯 개가 비슷하게. 협상은 모든 빌드에 들어가서 최대 포인트를 낮춤(20)
- 근성(켜둔 시간 보너스)은 뺌: 오래 켜둘 수 있는 유저만 유리해짐
- 처음 보는 사람이 막막하지 않게: 능력치마다 한 줄 설명 + 예시 빌드 소개 (돈벌이, 스피드, 쉬엄쉬엄, 강화)
- 만렙까지 받는 포인트는 5개를 다 찍기에 모자람 → 유저마다 빌드가 갈림. 협상이 모든 빌드에 들어가니까 너무 세지 않게 조절
- **능력치 초기화: 무료, 횟수 제한 없음.** 빌드를 마음대로 실험하고 상황 따라 바꿀 수 있게 (예: 고강 도전할 때만 정비 지식)
- **능력치 업데이트 (출시 후):** 만렙 확장 + 새 능력치 추가. 후보: 리더십(보조 트럭 수익, 회사 단계 확장 때), 손재주, 흥정, 영업력, 말빨, 동네 인맥, 명장 인맥
- 뺀 것: 평판(회사 평판이랑 겹침), 운(세팅 확률 밸런스 위험), 길 숙련(내비 부품이랑 겹침), 세무 지식(세무사 NPC 업데이트 몫), 꼼꼼함(배송 사고 = 손해 원칙 위반), 야간 근무(야간 배송팀 80% 제한이랑 겹침), 침착함(강화 하락이 없어서 의미 없음)

### 4.9 오프라인 진행 [확정] — 숫자는 시트 "오프라인"
- 꺼둔 동안 들어온 택배가 물류센터 창고에 쌓이고, 차면 더 안 쌓임
- 창고 확장(쌓이는 시간), 야간 배송팀(버는 속도, 최대 80%). 창고 12시간은 대리점부터

### 4.10 돈: 수입과 지출 — 숫자는 시트 "수입원", "지출", "회사 단계"
**출시 버전 수입원:** 내 트럭 배송, 보조 트럭 배송, 출력 제한 배송(장거리·대형·VIP), 기업 계약(16.5), 랜덤 전화(급송 요청)
**업데이트 수입원:** 무인 택배함, 냉동 화물, 창고 보관료, 광고 랩핑(광고비를 받는 대신 내 랩핑 대신 광고가 보임)

**지출:** 창업 비용, 보조 트럭, 직원 고용, 월급, 세금, 스페어 엔진, 강화·세팅 비용, 랩핑, 기름값·정비비(배송 단가의 %), 물류센터 업그레이드
- **뭘 사든 "본전 뽑는 시간"이 정해져 있어야 함.** 초반엔 짧고 후반엔 길게
- **월급 = 직원이 번 돈의 일정 비율.** 고정 월급이면 꺼둔 동안 마이너스가 될 수 있음 (원칙 1 위반)
- **세금 = 회사 단계별 낮은 세율.** 매출 금액 구간은 돈 단위가 커질 때마다 다시 맞춰야 해서 단계별로 나눔. 세율표 전체를 처음부터 공개, 번 돈에서 자동 차감, 밀린 세금·벌금 없음
- 화면: "오늘 순이익" = 매출 - 직원 몫 - 세금, 지출 내역
- 업데이트: 세무사 NPC (세금 감소, 원칙 2)

### 4.11 보조 트럭 [확정]
- 대리점부터. 메인처럼 강화·세팅 다 됨 → 후반에 돈 쓸 곳이 확 늘어남
- 그림은 같은 템플릿·부품 재사용, 차체 크기·색만 다르게
- 정비소 화면 위쪽에 트럭 고르는 탭
- 보조 트럭 기사(직원)는 능력치 없음 (나중에 업데이트)
- [확정] 강화 상한은 메인과 같은 +30
- 주의: 트럭 대수만큼 수입이 곱해져서 후반 밸런스가 어려워짐 → 시뮬레이터에 "보조 트럭 전부 +25 이상" 상황을 꼭 넣기

### 4.12 랜덤 전화 이벤트 [초안]
- **[확정]** 30~60분에 1번, 켜둔 동안만, 알림은 작게, 설정에서 끌 수 있음
- 출시 2종: **급송 요청**(받으면 다음 배송 몇 건 보상↑, 무시하면 사라짐·손해 없음. '+18 VIP 귀중품'과 이름이 겹쳐서 바꿈), 명장 예고 전화

## 6. 화면 & 아트

### 6.1 두 가지 모드 [확정]
- **띠 모드:** 바탕화면 오른쪽 아래, 작업표시줄 위. 건물 + 작은 버튼만 클릭, 나머지는 바탕화면으로 클릭 통과. 건물에 마우스 올리면 빛남 + 이름표, 누르면 그 건물 화면으로
- **정비소 화면:** 창 모드 또는 전체 화면. Cast n Chill 같은 UI + NPC. 위쪽에 트럭 고르는 탭

### 6.2 그림 방향
- 배경·NPC는 아늑한 픽셀 아트 (빛 변화, 비 오는 날, 골목 고양이)
- 차는 픽셀 아트지만 해상도를 크게. 같은 부품을 띠 모드용·정비소용 두 크기로 따로 그림
- 레이어 순서: 바퀴 → 차체 → 랩핑(도색·무늬) → 데칼 → 등급 외형 부품 → 강화·세팅 효과
- 강화 단계·세팅 등급이 띠 모드에서도 보여야 자랑할 맛이 남
- 그림 양 조심: 등급마다 완전히 새로 그리지 말고 테두리 색·반짝임 추가로. 낮은 두 등급은 같은 그림 공유 가능

### 6.3 그림 제작 도구 [확정]
| 만들 것 | 도구 |
|---|---|
| 차 템플릿, 부품, 건물, NPC, 배경 | PixelLab → Aseprite에서 다듬기 |
| NPC 숨쉬기, 바퀴 같은 짧은 반복 동작 (2~4프레임) | PixelLab 애니메이션 |
| 엔진 퍼짐 폭발, 강화 성공 반짝임, 배기 불꽃 (한 번 터지는 효과) | PixelLab 효과(VFX) → 스프라이트 시트 |
| **속도 연출** (바퀴 회전, 배경 흐름, 속도선, 배기 연기, 오버부스트 튀어나감·잔상) | **Godot 코드** (파티클, 셰이더, 트윈). 속도 숫자에 비례해야 해서 그림으로 미리 못 만듦 |
| 도색(색 바꾸기) | Godot 셰이더 (회색조 차체 + 색만 교체) |
| 버튼, 창 같은 화면 요소 | Godot 기본 기능 + PixelLab 일부 |

- **PixelLab을 고른 이유:** 픽셀 전용(픽셀 단위로 그림), 참고 이미지로 스타일 맞추기, 원본을 보면서 고치는 인페인팅(휠만 바꾸기 등), Aseprite 플러그인, Claude Code에 MCP로 연결돼서 에이전트가 직접 그림을 뽑을 수 있음, 효과 그림을 스프라이트 시트로 내보냄. 상업적 사용 가능 (대신 AI 학습에 쓰면 안 됨)
- **요금:** 월 12달러로 시작해서 차 템플릿 1개 + 부품 몇 개로 톤 테스트 → 본격 생산 때 24달러로. (공식 가격표는 결제 전에 직접 확인)
- **Aseprite:** 따로 구매 (한 번 사면 계속, 약 20달러)
- **힉스필드는 안 씀:** 게임 안 그림은 PixelLab이 낫고, 홍보 영상은 실제 게임 화면을 녹화해야 함 (스팀 트레일러에 실제 게임이 아닌 장면은 문제)
- 스팀 규칙: 게임 안 AI 그림·소리·글, 스토어 이미지·홍보물은 표시 필수. 코딩 보조는 해당 없음
- 일관성: 고정 팔레트, 고정 격자, **차 템플릿 1개를 가장 먼저 확정**하고 모든 부품을 그 위에서 뽑기
- 반발이 가장 큰 곳은 스토어 대표 이미지 → 캡슐 제작 방식은 따로 결정

## 7. 기술 구조 (Godot, 큰 그림)

- **트럭을 처음부터 여러 대 기준으로 설계:** 트럭마다 번호 → 그 밑에 부품, 강화 단계, 세팅 줄, 천장 카운터(부품·등급별), 외형 고정 여부, 랩핑. 1대짜리로 만들고 나중에 늘리면 거의 다 뜯어고쳐야 함
- **창:** 테두리 없음, 투명, 픽셀 단위 투명. 클릭 영역 지정(mouse_passthrough_polygon)으로 건물 + 버튼만 클릭. 작업표시줄을 뺀 영역 맨 아래에 배치
- **모드 전환:** 창 하나로 크기·테두리·투명 전환. 경제 데이터는 화면과 분리된 관리자 객체(싱글톤)에
- **가벼움:** 띠 모드에서 저전력 모드 + 10~30fps. 경제 계산은 1초에 1번
- **저장:** user:// 폴더에 JSON + 마지막 종료 시각. 자동 저장 + 강화·세팅 버튼 누른 직후 저장
- **스팀:** GodotSteam으로 업적·클라우드. 리더보드는 출시 후
- **데이터 파일로 관리:** 강화 확률·출력표, 세팅 확률·옵션·수치, 부품, 랩핑, 이벤트 보너스, 전화 이벤트, 능력치, 레벨 곡선, 회사 단계·세율, 수입원 → 시트에서 바로 옮길 수 있게
- **1주차 기술 검증:** 24시간 켜두기 (Windows 10, 11), 멀티 모니터, 작업표시줄 위치·화면 배율 변경

## 10. 출시 버전 범위 (MVP)

1. 띠 모드: 동네 도로, 집, 물류센터, 트럭, 돈 표시
2. 건물 클릭 + 작은 버튼 → 정비소 화면 (트럭 고르는 탭)
3. 엔진 강화 +0~+30: 출력(기본 이동 속도), 퍼짐, 스페어 엔진, 출력 제한 배송 3종
4. 세팅 돌리기: 부품 4개, 공용·전용·잡옵, 메모리얼, 천장 카운터, 등급별 외형 + 외형 고정
5. NPC: 카센터, 튜닝숍, 랩핑샵, 물류센터 팀장, 명장, 보험사, 마술사, 중고 부품상
6. 이벤트: 명장 방문일(요일 선택, 강화 버프) + 보험사·마술사·중고 부품상(각자 3~4주에 한 번) + 급송 전화 + 주간 배송 목표. 편지봉투 알림
7. 기사 레벨(만렙 50) + 능력치 5개(처음부터 전부 열림) + 초기화, 만렙 후 회사 평판
8. 회사 단계: 개인 기사 → 대리점 (시내 + 장거리 노선 1개), 라이벌 순위표 (위쪽 잠김)
9. 보조 트럭 2~3대 (강화·세팅 다 됨), 직원 고용, 월급(수익 나눠 갖기), 세금, 오늘 순이익 화면
10. 수입원: 배송, 보조 트럭, 출력 제한 배송, 기업 계약(3개), 랜덤 전화
11. 창고 확장 + 야간 배송팀
12. 랩핑 4개
13. 랜덤 전화 2종 (급송 요청, 명장 예고)
14. 설정: 소리, 알림, 띠 높이·위치, 투명도, 모니터 선택
15. 스팀 업적 20개, 클라우드 저장
16. 한국어 + 영어
17. 퀘스트 '다음 할 일' 목록 20~30개
18. 물류센터 업그레이드 3개 × Lv1~5 (동네, 제일 먼저 자를 수 있게 따로)

### 15.3 띠 클릭 방식 (1주차 기술 검증 1순위)
- **함정:** Godot의 클릭 통과 영역 기능은 Windows에서 그 영역 밖을 아예 안 그림 → "띠 전체는 보이는데 빈 곳 클릭은 뒤로 통과"를 그냥은 못 만듦
- **[확정] 지금 방식 (v1에서 Godot 4.6.3으로 직접 확인):** 보이는 것 = 클릭 받는 곳. 창 전체 클릭 통과를 껐다 켜는 방식은 다른 프로그램으로 클릭이 안 넘어가서 못 씀
- **[확정] 반응:** 건물(마우스 올리면 빛남 + 이름표, 누르면 그 건물 화면)과 작은 버튼(튜닝숍 화면)만. 도로·트럭은 눌러도 아무 일 없음. 오른쪽 클릭 메뉴는 그대로
- 항상 위: 기본 ON + 전체화면 앱·게임이 켜지면 자동 숨기기 + 설정에서 끌 수 있음
- 탈출구: 투명하지 않은 일반 창 모드 (그래픽 드라이버에 따라 투명 창이 검은 상자로 나오는 버그가 흔함)
- 테스트: 24시간 켜두기 (Win 10, 11), 144·240Hz 모니터, 노트북 내장 그래픽, 듀얼 모니터 + 모니터 연결 해제, 작업표시줄 위치·화면 배율 변경, CPU 사용량

### 15.4 돈과 숫자
- 돈은 64비트 정수로 저장 (약 900경까지). 출시 버전 최대 금액을 미리 정하고, 나중 단계(전국·세계)에서도 안 넘치게 단위 설계
- **비용은 단계마다 곱하기로 커지고, 수입은 더하기로 커지는 모양**이 기본 (비용 = 기본값 × 배수^단계)
- 화면 표기: 한국어 "1.2만 / 3.4억", 영어 "12K / 340M"
- **곱셈 폭주 점검:** 강화 고정 속도 × 세팅 % × 오버부스트 × 트럭 대수 × 협상 × 팁이 다 곱해짐. 시뮬레이터에서 "전부 최대일 때" 반드시 확인. 업데이트로 수입원이 늘 때를 대비해 다음 단계 비용 배수는 미리 높게

- 설정: 띠 크기·배율, 모니터 선택, 투명도, 항상 위, 알림, 언어, 숫자 표기
- 소리: 배경음악·환경음·효과음 따로 조절, 전체 음소거, 다른 창 볼 때 소리 줄이기
- 확률·천장 표시
- 통계·도감: 총 배달 수, 최고 강화, 퍼짐 횟수, 잡옵 도감 (컵홀더 수집)
- 업적 20개 (출시), 업데이트 때 추가
- 텍스트를 처음부터 번역 파일로 분리 (나중에 중국어·일본어 추가 쉽게)
- [확정] 서포터 팩은 출시 후 (Rusty는 4달러 금색 의상 팩으로 11만 1천 달러, 구매자 약 11%. 나오면 랩핑샵 스킨으로. 유료 추가 콘텐츠는 스토어 페이지를 따로 만들어 검수받아야 함)

## 16. grillme 확정 (2026-11-13)

> 기획서·시트·지금 코드가 서로 안 맞던 곳을 정했다. 위 장이나 시트의 규칙 글과 다르면 여기를 따른다.

### 16.1 엔진 강화
- **실패 = 단계 유지 (하락 없음).** 원칙 1 그대로. 그래서 명장 보너스 '실패해도 안 떨어짐'과 능력치 '침착함'은 뺌
- **비용 = 단계별 고정표** (기본값 × 배수^단계, 숫자는 balance.json). 수입과 무관 → 세팅·보조 트럭·능력치로 수입을 올리면 강화도 그만큼 빨라짐. 보조 트럭도 같은 표
- **스페어 엔진:** 카센터 고정가 구매 + 배송 중 낮은 확률로 카센터 사장이 챙겨줌 (꺼둔 동안도 평균값으로). 정비 지식(최대 2배)이 이 확률을 올림. **드랍 목표: 가볍게 하는 유저 기준 약 2주에 1개** (정비 지식 최대면 약 1주에 1개). 시트의 "스페어 부품" = 스페어 엔진
- **+18 이상 강화는 스페어(보통 또는 고급) 1개를 들고 있어야 누름** (보험 걸면 불필요). 퍼지면 자동으로 써서 +15 → 트럭이 멈추는 상태가 없음
- **보험:** 보험사가 온 날 "예"를 누른 경우에만 (4.7, 16.10). 보험 쿠폰 없음. 보험이 퍼짐을 막으면 그 회는 실패(단계 유지)
- **화면 표기는 "+18".** ★ 없앰 (큰 화면에 계기판 바늘 그림은 곁들임)

### 16.2 돈 계산
- 최종 속도 = 엔진 출력 × (1 + 세팅 이동 속도 % 합). %끼리는 더함 (곱하지 않음)
- 한 바퀴: 물류센터에서 N개 싣고 → N집 돌고 → 복귀
  - 시간 = 싣는 시간 + 도로 길이 ÷ 속도 + N × 집 앞 정차 시간
  - 수입 = N × 단가 − 기름값·정비비
  - N = 적재량 (기본 적재함 크기 + 적재함 세팅 %)
- 기름값·정비비 = 배송 단가의 일정 % (정액이 아니라서 돈이 마이너스 될 일 없음). 절감 옵션 상한은 각자 60% (기름값 절감 60%, 정비비 감소 60%). "오늘 순이익"에 보임
- 이동 속도 합에 상한 없음 → 시뮬 "전부 최대일 때"로 점검. 빨라질수록 정차 시간이 병목이라 상하차가 빛남
- 오버부스트는 꺼둔 동안엔 평균값
- **화면 트럭은 계산 쪽 바퀴 진행을 그대로 따라 달린다** (2026-11-13 오후 사용자 결정: 강화하면 트럭이 눈에 띄게 빨라지는 것이 보상). 한 바퀴 8초에서 상한, 그 뒤는 속도선·잔상·배기 연기. "+돈" 표시는 계산 쪽 배송 완료에 맞춤
- **소수점 효과는 확률로:** 적재량처럼 개수로 바뀌는 것은 소수점을 확률로 처리 (21.6건 → 60%로 22건). 평균 계산은 소수점 그대로
- **오버부스트 = 바퀴 출발할 때 확률로 걸리고, 걸리면 그 바퀴 전체 운전 속도 2배** ("10초 동안"에서 바뀜)
- **기름값 = 배송 단가의 20%** (10%에서 올림. 기름값 절감 한 줄이 의미 있게)

### 16.3 세팅 돌리기
- 지금 프로토타입의 '튜닝 8칸'(등급만 오름)은 지우고 새로 만든다. 저장은 초기화 (출시 전이라 변환 안 함)
- 메모리얼 = 예전 상태(등급+줄) / 새 상태(등급+줄)를 통째로 고르기. 등급업이 떠도 예전 걸 고를 수 있음
- 천장 카운터는 등급업이 뜬 순간 0 (안 골라도). 천장 판을 버리며 좋은 줄만 낚는 꼼수 방지

### 16.4 열리는 순서
| 조건 | 열리는 것 |
|---|---|
| 처음 | 동네, 적재함, 물류센터 업그레이드 |
| 엔진 +5 | ECU |
| 엔진 +10 | 명장 방문일 (요일 고르기), 보험사·마술사·중고 부품상 방문 |
| 엔진 +15 / +18 | 대형 화물 / VIP 귀중품 (무대 상관없이 **지금** 단계 기준 → 퍼져서 +15면 VIP 잠김) |
| 대리점 창업 | 시내 (= 대리점 무대: 단가↑, 자주 멈춤, 도시 배경), 타이어·휠, 보조 트럭 + 직원, 세금 3%, 창고 12시간 |
| 대리점 + 엔진 +10 | 장거리 노선 (트럭마다 [시내 / 장거리] 스위치), 터보 |

### 16.5 기사·회사
- 만렙 = 가볍게 2주 (켜둔 약 35시간). 열심히는 그 결과 약 4~5일. 레벨 곡선 숫자는 배송 속도가 정해진 뒤 시뮬로 다시
- 능력치·경험치는 **내 트럭에만.** 협상은 기업 계약 금액에도. 친절은 기본 팁 확률(0보다 큼)에 더함. 노하우 경험치는 창고 상한 시간까지만
- **기업 계약:** 대리점에서 평판이 정해진 값에 닿을 때마다 1개 자동 체결 (최대 3). 계약 1개 = 시간당 고정 수입, 트럭 시간 안 씀, 꺼둔 동안은 야간 배송팀 %. 고르기·관리 없음
- **퀘스트** = 순서가 정해진 "다음 할 일" 목록 20~30개 (첫 배달, 첫 강화, 첫 세팅, +5, ECU, 창고 확장, 첫 능력치, 대리점 창업…). 한 번씩, 보상 경험치 + 돈. 튜토리얼 겸 "첫 3시간 새로운 것 10번" 장치. 반복은 주간 배송 목표 하나
- **순위표** = 켜둔 상태의 시간당 매출, 다음 순위까지 남은 양 표시. 시내 1위까지 가볍게 10~12주, 열심히 6~8주

### 16.6 그 밖
- **급송 전화:** 30~60분에 1번, 켜둔 동안만, 띠의 전화 아이콘을 5분 안에 누르면 내 트럭 다음 50건 단가 2배, 무시하면 사라짐 (손해 없음), 설정에서 끔
- **명장 주** = 월 0시~일 24시 (PC 현지 시간). 고른 요일 0~24시에 켜져 있으면 옴. 주간 배송 목표도 같은 기준
- **물류센터 업그레이드** (시트 '지출'의 "트럭 부품 단순 업그레이드"): 3개 × Lv1~5, 정해진 값만 오르는 단순 구매. 동네에서만 삼, 효과는 대리점 뒤에도 모든 트럭에 유지
  - 배송 구역 확장 = 단가 +% / 분류 속도 = 싣는 시간 ↓ / 기본 적재함 크기 = N +1
  - 일정이 밀리면 제일 먼저 자를 수 있게 따로 떼서 만든다
- 띠 클릭: 15.3

### 16.10 사용자 답 (2026-11-13 저녁 ~ 11-14, QUESTIONS Q17~Q25 + "사용자 답 3")
