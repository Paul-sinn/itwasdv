# 시제품 v6a 지시서: 건물 클릭 + 건물 화면 (튜닝숍·물류센터·카센터)

> 2026-11-13. 사용자가 자리를 비운 동안 조율자가 **추천안으로 정함** (물어볼 것은 바깥 폴더 `QUESTIONS.md` Q15).
> v6(기획서 16.9) 중 **숫자가 필요 없는 부분만** 먼저 한다. 명장 방문일·보험·쿠폰·주간 목표·급송 전화·대형 화물·VIP는 숫자 시트("명장 방문일" 탭 등)를 읽어야 하는데 시트 연결이 끊겨서 v6b로 미룬다.
> 새 숫자 없음 (`data/balance.json` 안 바뀜). 계산 코드도 안 바뀜. **화면 담당만 일한다.**
> 기획서: `docs/GAME_PLAN.md` 4.3, 6.1, 15.3 [확정]

## 이 시제품으로 알아낼 것 (딱 하나)

**띠에서 건물을 눌러 그 건물 화면으로 들어가는 구조가, 차고 하나에 칸 세 개보다 자연스러운가?** (v0 플레이 테스트 4번 "생각했던 구조랑 다른 UI"에 대한 답)

## 정한 것

| 항목 | 정한 것 |
|---|---|
| 띠의 건물 | 물류센터(지금 있음), 튜닝숍, 카센터 세 개. 그림은 임시 사각형 + 간판 글자. 랩핑샵은 v8, 대리점 사무실은 v7 |
| 건물 반응 | 마우스를 올리면 빛남 + 이름표, 누르면 큰 화면이 **그 건물 화면**으로 열림 |
| 작은 버튼 | 띠에 작은 버튼 하나. 누르면 튜닝숍 화면 (기획서 15.3) |
| 그 밖 | 도로·트럭·집·돈 표시·알림은 눌러도 아무 일 없음 (지금은 아무 데나 눌러도 큰 화면이 열림 → 바꿈). 오른쪽 클릭 메뉴와 알림 영역 아이콘은 그대로 |
| 큰 화면 | 차고의 칸 세 개([엔진 강화] [세팅 돌리기] [기사·물류센터])를 건물 화면 세 개로 다시 묶음. 위쪽에 건물 고르는 줄(튜닝숍 / 물류센터 / 카센터)이 있어 큰 화면 안에서도 오갈 수 있음 |
| 튜닝숍 화면 | 엔진 강화 + 세팅 돌리기 (안에서 두 칸) |
| 물류센터 화면 | 기사 레벨, 다음 할 일, 창고 확장, 야간 배송팀 (v5의 [기사·물류센터] 칸 내용 그대로) |
| 카센터 화면 | 스페어 엔진: 들고 있는 개수, 가격, [사기] 버튼, 설명 한 줄("+18부터 강화하려면 1개가 있어야 해요. 퍼지면 자동으로 써요"). 강화 칸에 있던 스페어 구매 버튼은 카센터로 옮기고, 강화 칸에는 개수 표시와 스페어가 없어서 막혔을 때 [카센터로] 버튼만 둠 |
| NPC | 건물 화면마다 임시 사각형 얼굴 + 이름 + 인사말 한 줄 (물류센터 팀장, 튜닝숍 사장, 카센터 사장). 그림·대사 늘리기는 그림이 나온 뒤 |
| 알림 영역·Esc·[작게] | 지금처럼. 알림 영역 아이콘 왼쪽 클릭은 마지막에 보던 건물 화면(처음엔 튜닝숍) |
| 고르다 만 세팅 | 켤 때 고르는 중인 부품이 있으면 튜닝숍 화면의 세팅 칸으로 (v4 동작 유지) |

## 코드 약속

계산 코드는 안 바뀐다. 화면 안의 약속만:

```gdscript
## main.gd
func open_building(id: String) -> void   ## "tuning" / "depot" / "car_center". 큰 화면으로 바꾸고 그 건물 화면을 보여 줌
## town.gd
func building_rects() -> Dictionary      ## 건물 id → Rect2 (작은 화면 좌표). 확인 스크립트와 visible_rects 가 같이 씀
```

## 범위

**만드는 것:** 위 전부.
**안 만드는 것:** 명장·보험·쿠폰·주간 목표·급송 전화·대형 화물·VIP(v6b), 랩핑샵(v8), 대리점 사무실(v7), NPC 그림·대사, 건물 화면 배경 그림.

## 작업 순서와 담당

화면 = `ui` 페인, 폴더 `itwasdv-town`, 가지 `v6a-ui`. 계산 담당은 일 없음.

| 단계 | 담당 | 고치는 파일 | 안 건드리는 파일 | 완료 기준 |
|---|---|---|---|---|
| U1 건물 클릭·건물 화면 | 화면 | `scripts/ui/*`, `scenes/`, `tests/check_*.gd`, `tests/error_watch.gd`, `locale/*` | `scripts/core/`, `data/`, `tools/`, `tests/test_*`, `tests/run_tests.gd` | "기존 확인" 전부 통과(종료 코드 0, 오류 줄 0) + 새 `tests/check_buildings.gd`가 진짜 클릭·마우스 이동으로 결과 줄을 찍음: ① 작은 화면에 건물 세 개와 작은 버튼이 있고 `visible_rects()` 안, 서로·집·돈 표시와 안 겹침 (창 크기 여러 가지) ② 건물에 마우스를 올리면 빛남 + 이름표(물류센터 / 튜닝숍 / 카센터), 벗어나면 꺼짐 ③ 건물마다 누르면 큰 화면이 그 건물 화면으로 열림 ④ 작은 버튼 → 튜닝숍 화면 ⑤ 도로·트럭·집·돈 표시·알림을 눌러도 작은 화면 그대로 ⑥ 큰 화면 위쪽 줄로 세 건물 화면을 오감, 고른 건물이 표시됨 ⑦ 튜닝숍에 강화·세팅 두 칸, 물류센터에 레벨·다음 할 일·창고·야간팀, 카센터에 스페어 개수·가격·[사기] ⑧ 카센터에서 사면 돈이 `Economy.spare_price`만큼 줄고 개수 +1, 직후 저장, 돈이 모자라면 버튼 꺼짐 + 모자란 금액 ⑨ +18에서 스페어 0이면 강화 칸에 이유 글 + [카센터로] 버튼, 누르면 카센터 화면 ⑩ 고르다 만 세팅이 있으면 켤 때 튜닝숍 세팅 칸 ⑪ [작게]·Esc 뒤 다시 건물을 누르면 그 건물 화면 ⑫ en에서도 건물 이름·NPC 인사말에 한글·키가 안 보임 ⑬ 오른쪽 클릭 메뉴는 건물·도로 어디서든 그대로 뜸 |

화면 글자: 건물 = 물류센터 / 튜닝숍 / 카센터. NPC = 팀장 / 사장. "차고"라는 말은 화면에서 없앤다(튜닝숍으로).
