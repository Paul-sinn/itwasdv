## 이 시제품으로 알아낼 것 (딱 하나)

**대리점을 차리고 트럭이 늘어나는 것이 "회사가 커진다"로 느껴지는가? (돈 쓸 곳이 늘어서 즐거운가, 관리가 귀찮은가)**

## 정한 것

| 항목 | 정한 것 | 근거 |
|---|---|---|
| 대리점 창업 | 물류센터에서 한 번 삼 (조건은 돈뿐). 사는 순간 회사 단계 = 대리점, 무대 이름 = 시내 | 기획서 4.2, 16.4 |
| 창업하면 열리는 것 | 타이어·휠 세팅, 보조 트럭 사기, 세금 3%, 창고 Lv4(12시간) 사기, 대리점 사무실 건물, 순위표 경쟁 | 기획서 16.4 |
| 시내 | **이번에는 이름과 경험치만:** 창업 뒤 내 트럭 배송 경험치 10 → 15. 도로·단가·그림은 그대로 | 스냅샷 7번. 그 밖의 "시내가 뭐가 다른가"는 기획서에 없음 → Q23 |
| 보조 트럭 | 최대 2대 더 (모두 3대). 사면 +0, 세팅 없음으로 시작해 바로 달림. 직원 고용은 트럭 값에 포함. 강화·세팅·스페어·보험·대형·VIP는 내 트럭과 같은 규칙. 능력치·급송·시내 경험치는 내 트럭만 (보조 트럭 배송 경험치 0) | 기획서 4.11, 16.5 |
| 직원 몫 | 보조 트럭이 번 돈(배송 1건 돈 + 팁)의 30%를 뗌. 꺼둔 동안도 같음 | 스냅샷 12번 |
| 세금 | 대리점이면 모든 트럭이 번 돈의 3%를 자동으로 뗌 (개인 기사는 0%). 세율표 전체(0/3/5/7/10%)를 화면에 공개 | 스냅샷 10번 |
| 떼는 순서 | 배송마다: 번 돈 → 직원 몫(보조 트럭만, 번 돈 × 30%) → 세금(번 돈 × 3%) → 나머지가 내 돈. 소수는 내 돈 쪽에서 버림 (직원 몫·세금은 반올림). 돈이 줄어드는 일 없음 | 기획서 4.10 |
| 오늘 순이익 | 오늘(현지 날짜 0시부터) 매출, 직원 몫, 세금, 순이익을 셈. 꺼둔 동안 번 것은 켠 날에 더함 | 기획서 4.10 |
| 타이어·휠 | 세 번째 세팅 부품. 창업하면 열림 (트럭마다 따로). 옵션: 이동 속도, 기름값 절감(공용), **정비비 감소(전용) 3/6/9/13/18%**, 잡옵 5개. 기름값 절감 + 정비비 감소 합 상한 60%는 지금 규칙 그대로 | 스냅샷 2·3·5번 |
| 순위표 | 가상 택배회사 10곳(시내)과 **켜 둔 상태의 시간당 매출**(모든 트럭 `Trip.hourly_income` 합, 직원 몫·세금 떼기 전)로 경쟁. 라이벌 숫자는 고정. 내 순위, 다음 순위까지 남은 양을 보여 줌. 지역·전국·세계 줄은 잠긴 채로 보임 | 기획서 4.2, 16.5 |
| 출시 버전의 끝 | 시내 1위가 되면 한 번 축하 알림 + "다음 업데이트에서 지역 진출". 그 뒤로도 그대로 계속 | 기획서 4.2 |
| 퀘스트 | 목록 끝에 3개 더: 대리점 창업, 보조 트럭 1대 사기, 타이어·휠 처음 돌리기 | 기획서 16.5 |

static func buy_helper(b: Balance, state: GameState) -> bool      ## trucks 에 새 TruckState. 이벤트 { "type": "helper_bought", "truck": i }

## 날짜가 바뀌면 today 를 0으로: Master.tick(state, b, now_local, rng) 안에서 (또는 Company.tick — 보고에 적기)

## 시뮬 (`tools/tune_sim.py`)

- 창업(돈이 모이면 삼, 그 전엔 강화에 쓰는 돈의 일부를 모음: 모으는 비율 인자), 보조 트럭 2대(사고 나서 돈을 트럭끼리 나눠 강화), 직원 몫·세금, 타이어, 창고 Lv4, 순위.
- 보고 (`_reports/balance_v7a.md`): ① 가볍게·열심히 유저가 며칠째 창업하는지 → `agency_price` 제안 ("가볍게 1~2주 모아야"가 되게. 창업 시점은 3~5주차쯤) ② 보조 트럭 본전(켜 둔 4~8시간) → `helper_prices` 제안 ③ 시내 1위까지: 가볍게 10~12주, 열심히 6~8주가 되는 `rivals` 10개 제안 (첫 라이벌은 창업 직후 바로 한두 곳 넘게) ④ 30일 판정이 창업을 모으느라 어떻게 바뀌는지 ⑤ "보조 트럭 전부 +25 이상", "전부 최대"일 때 시간당 매출 (곱셈 폭주 점검) ⑥ 정비비 감소 한 줄의 가치 (이동 속도 한 줄 대비). 제안은 diff로 (json에 넣지 않음). 강화 비용은 지금 json(35,000)과 Q21 제안(65,000) 둘 다로.
