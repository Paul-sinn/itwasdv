# 시제품 v0 지시서

## 이 시제품으로 알아낼 것 (딱 하나)

**"돈 모아서 강화 버튼 누르는 게 실제로 재밌나?"**

한 달 흐름 숫자는 시뮬로 이미 맞췄다. 시뮬이 못 알려주는 건 손맛뿐이다.
그래서 이 시제품은 예쁠 필요도, 기능이 많을 필요도 없다. 누르는 맛만 확인한다.

## 범위

**만드는 것**
- 트럭 1대, 동네 1개 (왼쪽 물류센터 ↔ 오른쪽 배송지 왕복)
- 배송하면 돈이 들어옴
- 엔진 강화 0~30강: 성공 / 실패(유지) / 퍼짐
- 퍼지면 고장 엔진(운행 정지) → 스페어 엔진 사서 수리
- 저장, 꺼둔 동안 쌓인 수익
- 작업표시줄 위에 붙는 투명 창
- 테스트용 치트 키

**안 만드는 것** (전부 `docs/IDEAS.md`에 있음. 손대지 말 것)
부캐 트럭, 기사 고용, 튜닝(큐브), 주소 불명 택배, 극한 배송, 틀린 주소 찾기, 주간 퀘스트,
급행 전화, 지역 확장, 튜닝 데이, 취업 단계, 스팀 연동, 진짜 그림, 소리(여유 되면 효과음만)

## 계산식 (숫자는 전부 `data/balance.json`)

이 시제품이 쓰는 건 `income`과 `engine` 두 묶음뿐이다.

```
시간당 수익(강수)   = base_hourly × star_mult ^ 강수
강화 1번 비용(강수) = cost_hours[강수] × 시간당 수익(강수)
스페어 가격         = spare_hours × 시간당 수익(퍼지기 직전 강수)
```
> **2026-11-10 바뀜 (사용자 결정, balance.json v0.4)**:
> - 시간당 수익: 19강까지 1강마다 `star_mult`(1.1)배, **`high_from_star`(20)강부터는 1강마다 `star_mult_high`(1.3)배**
> - 스페어 가격: **강수와 상관없는 고정 금액 `spare_price`(50,000원)**. `spare_hours`는 없어짐
> - 강화 비용 식은 그대로 (그 강수 수익의 N시간치 → 20강부터 비용도 같이 오름, 기다리는 시간은 그대로)

**강화 굴리기** (0 이상 1 미만 난수 r 하나 뽑음)
```
r < success[강수]                    → 성공: 강수 +1
r < success[강수] + destroy[강수]    → 퍼짐
그 외                                → 실패: 강수 그대로 (하락 없음)
```

**퍼짐**
- 퍼지기 직전 강수를 기억해 둔다 (스페어 가격 계산용)
- 강수를 `broken_drop_to`(15)로 내린다
- 고장 상태가 된다: 트럭이 멈추고 수익 0, 강화 불가
- 스페어 엔진을 사면 고장이 풀린다 (강수는 15 그대로)
- 퍼질 수 있는 강수(`destroy > 0`)에서는 **강화 비용 + 스페어값(그 강수에서 퍼졌을 때 가격)**이
  있어야 강화 버튼이 눌린다. 빠지는 돈은 강화 비용뿐. 퍼져도 스페어는 반드시 살 수 있게 해서
  수익 0으로 영영 갇히지 않게 한다 (플레이 테스트 뒤 사용자 결정, 2026-11-10)

**꺼둔 동안 수익**
```
쌓인 돈 = 시간당 수익 × min(꺼둔 시간, offline_cap_hours) × offline_rate
```
- 고장 상태였으면 0
- 컴퓨터 시계가 거꾸로 갔으면(꺼둔 시간이 음수) 0
- 지금은 컴퓨터 시계를 그대로 쓴다. 시계 조작 방지는 나중 (IDEAS 참고)

**배송 한 번에 받는 돈** = 시간당 수익 ÷ 3600 × 그 배송에 걸린 초
(트럭이 빨라져도 시간당 수익은 위 식과 정확히 같아야 한다. 속도는 눈에 보이는 연출일 뿐)

**확인용 정답 값** (테스트에 쓸 것)
| 강화 | 1번 비용 |
|---|---|
| 0→1강 | 20 |
| 10→11강 | 약 1,037 |
| 17→18강 | 약 45,490 |
| 19→20강 | 약 122,318 |
| 18강에서 퍼졌을 때 스페어 | ~~약 133,438~~ → 50,000 (고정, v0.4) |

## 화면

**띠** (작업표시줄 바로 위, 화면 가로 전체, 높이 약 120px)
- 왼쪽 물류센터, 오른쪽 집, 그 사이를 트럭이 왕복
- 배송 완료 시 트럭 위로 "+금액"이 떠오름
- 구석에 현재 돈, 시간당 수익, 엔진 강수(★ 숫자)
- 강수가 오를수록 트럭이 빨라 보이게 (하한 있음)
- 고장 상태면 트럭이 멈추고 연기

**차고 패널** (트럭을 클릭하면 띠 위쪽에 열림, 다시 클릭하거나 바깥 누르면 닫힘)
- 현재 강수, 시간당 수익, 강화하면 시간당 수익이 얼마 되는지
- 다음 강화의 성공 % / 실패(유지) % / 퍼짐 %
- 비용. 돈이 모자라면 버튼 비활성 + "약 N분 뒤 가능"
- [강화] 버튼
- 퍼짐 확률이 0보다 크면: 패널 테두리 경고색 + "퍼질 확률 N%" 크게 표시
  + "스페어값 N원은 남겨둬야 누를 수 있음", 모자라면 "강화 비용 부족 · 약 N시간 뒤 가능"
- 고장 상태일 때: "엔진 고장 - 운행 정지" + [스페어 엔진 구매 (가격)] 버튼만 보임
- 맨 아래 작게: 지금까지 누른 횟수, 성공 / 실패 / 퍼짐 횟수

**강화 연출** (이게 시제품의 핵심. 대충 넘기지 말 것)
- 버튼 누르면 결과 나오기 전 짧은 뜸 (안전 구간 약 0.4초, 퍼짐 구간 약 1초 + 엔진 떨림)
- 성공: 번쩍임 + ★ 숫자 커졌다 돌아옴 + 트럭이 순간 가속
- 실패: 패널 살짝 흔들림 + 회색 "실패"
- 퍼짐: 화면 흔들림 + 연기 + 빨간 "엔진 퍼짐!" + 트럭 정지
- 연출 숫자(시간, 세기)는 `scripts/ui/feel.gd`에 모아서 쉽게 고칠 수 있게

**복귀 팝업**: 게임 켰을 때 "자리 비운 N시간 동안 +금액"

## 치트 키 (디버그 실행일 때만 동작)
- F1: 돈 + (현재 시간당 수익 × 1시간)
- F2: 시간 60배속 켜기/끄기
- F3: 저장 초기화
- F4: 강수 +1 (18강 이상 구간을 바로 체험하려고)
- F5: 강제로 퍼지게 하기 (고장 → 스페어 흐름 확인용)

## 작업 순서

각 단계가 끝나면 멈추고 확인받을 것. 단계마다 커밋.

**0단계: 준비**
- 설치된 Godot 버전과 실행 파일 경로를 사용자에게 확인. `CLAUDE.md`의 "명령"에 적기
- Godot 프로젝트 생성, 폴더 구조 만들기, git 초기화

**1단계: 계산 코드 (화면 없음)**
- `balance.gd`: balance.json 읽기 + 검사 (success / destroy / cost_hours 길이가 max_star와 같은지,
  각 강수에서 success + destroy가 1 이하인지). 틀리면 어디가 틀렸는지 알려주고 멈춤
- `economy.gd`: 시간당 수익, 강화 비용, 스페어 가격, 꺼둔 동안 수익
- `enhance.gd`: 강화 굴리기. 난수 생성기를 밖에서 넣어줄 수 있게 (테스트용)
- `game_state.gd`: 돈, 강수, 고장 여부, 퍼지기 직전 강수, 통계
- 테스트 (화면 없이 실행):
  - 위 "확인용 정답 값"과 일치
  - 강수별로 10만 번 굴려서 성공률·퍼짐률이 표와 1%p 안쪽
  - 17강 이하에서는 절대 안 퍼짐
  - 퍼지면 15강 + 고장, 스페어 사면 고장만 풀림
- 완료 기준: 테스트 전부 통과

**2단계: 띠 화면 (일단 평범한 창에서)**
- 트럭 왕복, 배송마다 돈 증가, 돈·수익·강수 표시
- 완료 기준: 1시간(F2로 1분) 돌렸을 때 번 돈이 "시간당 수익"과 1% 안쪽으로 맞음

**3단계: 차고 패널과 강화**
- 패널, 강화 버튼, 결과 반영, 고장과 스페어 구매, 치트 키
- 완료 기준: F4/F5로 0강~30강, 퍼짐 → 수리까지 전부 눌러볼 수 있음

**4단계: 저장과 꺼둔 동안 수익**
- 30초마다 + 끌 때 저장 (`user://`). 저장 파일이 깨졌으면 새로 시작
- 복귀 팝업
- 완료 기준: 껐다 켜도 상태 유지. 저장 파일의 시간을 손으로 3시간 전 / 20시간 전 / 미래로 바꿔서
  각각 3시간치의 절반 / 8시간치의 절반 / 0이 들어오는지 확인

**5단계: 투명 창**
- 배경 투명, 테두리 없음, 항상 위, 작업표시줄 바로 위에 붙이기
- 트럭·패널·버튼만 클릭되고 나머지는 클릭이 뒤 창으로 통과
- 완료 기준:
  - 띠 뒤의 바탕화면 아이콘과 다른 창을 평소처럼 클릭할 수 있음
  - **2시간 켜두고 다른 작업 해도** 화면이 어두워지거나 작업표시줄이 깨지지 않음
    (Windows에서 투명 창 + 클릭 통과를 오래 켜두면 화면이 깨진다는 신고가 있음. 꼭 확인)
  - 문제 생기면 원인과 우회 방법을 정리해서 보고. 혼자 큰 구조를 바꾸지 말 것

**6단계: 연출 다듬기**
- "강화 연출" 항목 전부 구현
- 완료 기준: 아래 플레이 테스트를 할 수 있는 상태

## 플레이 테스트 (사용자가 직접)

30분 정도 그냥 플레이 + F4로 18강 넘겨서 10분.

1. 강화 버튼 누를 때 두근거리나?
2. 18강 넘어서 누를 때 겁이 나나?
3. 돈 모일 때까지 기다렸다가 다시 눌러보고 싶나?
4. 켜둔 채로 다른 일 할 때 안 거슬리나?
5. 퍼졌을 때 "아..." 하면서도 스페어 사서 다시 하고 싶나?

"아니오"가 2개 이상이면 기능을 더 붙이지 말고, 연출과 속도(`feel.gd`, `cost_hours`)부터 고친다.
