## 정한 것

### 가. 대형 화물·VIP 귀중품 (출력 제한 배송)

| 항목 | 정한 것 | 근거 |
|---|---|---|
| 열림 | 그 트럭의 **지금** 단계가 +15 이상이면 대형 화물, +18 이상이면 VIP 귀중품도. 퍼져서 +15가 되면 VIP는 다시 잠김 | 기획서 4.4, 16.4 |
| 방식 | 배송 1건마다 굴림: VIP 몫(열렸을 때) → 아니면 대형 몫(열렸을 때) → 아니면 보통. 평균 계산(시간당 수입, 꺼둔 동안)은 몫 그대로 | **조율자가 정함** (기획서에 "받을 수 있는 배송"만 있고 얼마나 섞이는지 없음 → Q20) |
| 단가 | 대형 = 단가 ×3, VIP = 단가 ×5 (초안). 협상·기름값·정비비·팁은 그 단가 기준으로 그대로 계산 | Q15 답 |
| 모든 트럭 | 트럭마다 자기 단계로 판정 (능력치가 아니라 엔진 단계라서) | |

### 나. 급송 요청 전화

| 항목 | 정한 것 | 근거 |
|---|---|---|
| 언제 | 켜 둔 동안만, 30~60분(고르게 랜덤)에 1번 벨이 울림 | 기획서 16.6 |
| 받으면 | 내 트럭(트럭 0)의 다음 배송 N건이 단가 ×2. 무시하면(벨이 끝나면) 사라짐, 손해 없음 | 기획서 4.12, Q15 답 |
| 끄기 | [설정]에서 끌 수 있음 (끄면 벨이 안 울림) | 기획서 16.6 |
| 겹침 | 급송이 남아 있는 동안에는 다음 벨 시계가 안 감 | 조율자가 정함 |

### 다. 주간 배송 목표·보험 쿠폰

| 항목 | 정한 것 | 근거 |
|---|---|---|
| 한 주 | 월 0시 ~ 일 24시 (PC 현지 시간). 주가 바뀌면 진행이 0으로 | 기획서 16.6 |
| 목표 | 그 주에 배송 N건 (모든 트럭, 꺼둔 동안 배송 포함). 차면 자동으로 보상: 보험 쿠폰 1장 + 경험치 2,000. 한 주에 한 번 | 스냅샷 7번, 9번 |
| 열림 | 처음부터 | 조율자가 정함 |
| 쿠폰 | 강화 1회를 추가 요금 없이 보험. 쌓기 상한 없음. 아무 날이나 | 기획서 16.1 |

### 라. 명장 방문일·보험

| 항목 | 정한 것 | 근거 |
|---|---|---|
| 열림 | 엔진 +10 첫 달성 때. 그때 "어떤 요일에 명장이 오면 좋겠어요?"를 물어봄 | 기획서 2장 |
| 요일 | 유저가 고름. **처음 고른 것은 이번 주부터**(그 요일이 이미 지났으면 이번 주는 없음), **바꾸면 다음 주부터** | Q15 답, 스냅샷 9번 |
| 방문 | 고른 요일 0~24시에 게임이 켜져 있으면 그날 내내 방문 중. 안 켜면 그 주는 없음 | 스냅샷 9번 |
| 그 주 보너스 | 주마다 7개 중 1개 랜덤. **방문 중인 날에만 적용** | 스냅샷 9번 |
| 예고 | 방문 전날 게임이 켜져 있으면 전화(알림)로 "내일 명장이 와요 + 그 주 보너스". 한 주에 한 번. 예고한 보너스 = 방문일 보너스 | 스냅샷 9번 |
| 보험 | 방문 중이면 강화할 때마다 켤 수 있음: 추가 요금 = 그 회 강화 비용 × 2. 방문일이 아니면 쿠폰 1장을 써서 (추가 요금 없음). 보험을 건 회에 퍼짐이 뜨면 **실패(단계 유지)** 로 바뀜. 보험을 걸면 +18 이상에서 스페어가 없어도 누를 수 있음 | 기획서 16.1, Q15 답 |
| 시계 | 현지 시각은 화면이 넘겨 준다 (계산 코드는 시계를 직접 안 읽음: 테스트할 수 있게). 시계 조작은 허용. 시계가 거꾸로 가도 멈추지 않음 | 기획서 4.7 |

보너스 7개 (방문 중에만):

| id | 효과 | 수치 (초안) |
|---|---|---|
| `destroy_cut` | 퍼짐 확률 × (1 − 0.3). ECU 엔진 보호와는 곱으로 | 30% |
| `enhance_discount` | 강화 비용 × (1 − 0.2). 보험 추가 요금도 할인된 비용 기준 | 20% |
| `setting_up_mult` | 세팅 등급업 확률 × 1.5 (천장은 그대로) | 1.5배 |
| `success_mult` | 강화 성공 확률 × 1.2 (성공 + 퍼짐이 1을 넘으면 성공을 자름) | 1.2배 |
| `spare_mult` | 스페어 드랍 확률 × 2 (정비 지식과는 곱으로. 켜 둔 동안만) | 2배 |
| `setting_discount` | 세팅 돌리기 비용 × (1 − 0.2) | 20% |
| `double_step` | 강화 성공 때 10%로 한 단계 더 (+30은 안 넘음) | 10% |

- 굴리기 위치: 강화(보험·성공 배수·2단계)는 `enhance.gd`, 화물 종류·스페어는 `trip.gd`, 급송 벨 간격은 `rush.gd`, 그 주 보너스는 `master.gd`.
- 꺼둔 동안: 대형·VIP는 평균으로 들어감. 급송·명장 보너스는 안 들어감. 주간 진행에는 꺼둔 동안 배송이 더해짐 (주가 바뀐 뒤 켰으면 새 주에).
- 저장 형식을 올린다. 옛 형식(3~7)은 그대로 읽음.

## 화면

| 항목 | 정한 것 |
|---|---|
| 대형·VIP 배송 | 동네 "+금액"을 종류마다 다른 색으로 + 앞에 글자 ("대형", "VIP"). 급송 중인 배송은 "급송" |
| 급송 전화 | 벨이 울리면 작은 화면·큰 화면 둘 다 동네에 전화 말풍선 "급송 요청! [받기]" + 남은 시간 줄어드는 표시. [받기]를 누르면 "급송 N건 남음"이 구석 줄에. 벨이 끝나면 조용히 사라짐. `visible_rects()`에 넣기 |
| [설정] | "급송 요청 전화" 켜기 / 끄기 한 줄 |
| 주간 배송 목표 | 물류센터 [창고·할 일] 칸에 "이번 주 배송 12,340 / 30,000건 → 보험 쿠폰 1장 + 경험치 2,000", 찼으면 "이번 주 달성!". 달성 알림은 동네 알림으로 |
| 요일 고르기 | `master_unlocked` 이벤트가 오면 큰 화면 튜닝숍에 요일 7개 버튼이 있는 창. 안 고르고 닫아도 튜닝숍 [명장] 칸에서 언제든 고를 수 있음 |
| 튜닝숍 [명장] | 튜닝숍 화면의 세 번째 칸 ([엔진 강화] [세팅 돌리기] [명장]). 잠겼으면 "+10을 달성하면 명장이 찾아와요". 열렸으면: 고른 요일, 바꾸는 버튼 7개("다음 주부터 ○요일"), 이번 주 보너스(예고를 받았거나 방문 중일 때만 보임, 아니면 "전날 전화로 알려 줘요"), 오늘 방문 중이면 "오늘 명장이 와 있어요!" |
| 강화 칸 | 방문 중이면 위에 "명장 방문 중: <보너스 이름과 효과>" 한 줄. [보험] 켜기 버튼: 방문 중이거나 쿠폰이 있을 때만 켤 수 있음. 켜면 비용 줄에 "보험 +N원" 또는 "쿠폰 1장 사용 (N장 남음)", 퍼짐 확률 자리에 "퍼져도 단계 유지". 보험이 퍼짐을 막았으면 결과 글 "보험 덕분에 살았어요". 2단계 오르면 "+2!" |
| 강화 "몇 번 시도 가능" | 강화 칸에 "지금 돈이면 N번 시도 가능" (보험 켰으면 보험 포함 비용으로). 계산은 `Economy` 쪽 함수로 (없으면 계산 담당에 요청) |
| 알림 | 예고 "내일 명장이 와요: <보너스>", 방문 "오늘 명장이 와 있어요: <보너스>" (동네 알림) |
| 작은 화면 | 방문 중이면 튜닝숍 건물에 표시 하나(임시: 별 모양 글자 또는 색 테두리). `visible_rects()` 안 |

화면 글자: 명장, 보험, 보험 쿠폰, 급송 요청, 대형 화물, VIP 귀중품, 주간 배송 목표. 요일은 월~일. en 임시: Master, Insurance, Coupon, Rush order, Large cargo, VIP valuables, Weekly goal.
