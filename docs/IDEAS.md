# 이미 정한 것 / 나중에 할 것

시제품 v0에서는 아래 어느 것도 만들지 않는다. 방향만 적어둔 문서.

## 이미 정한 것
- 스팀 유료 게임, 한 번 구매. 게임 안 결제(돈으로 재화 사기) 없음
- 작업표시줄 위 띠에 사는 데스크톱 방치형, 테마는 택배
- 엔진 강화: 최대 30강, 실패하면 유지, 18강부터 퍼짐. 30강은 사실상 로또
- 퍼지면 15강 고장 엔진 + 운행 정지, 스페어 엔진으로 수리
- 확률은 게임 안에서 전부 공개
- 스팀 장터에서 아이템 사고팔기는 넣지 않음 (봇 몰림)
- 숫자는 `data/balance.json` 하나에. 시뮬(`tools/delivery_sim.py`)과 게임이 같이 읽음

## 나중에 할 것 (대략 순서대로)
1. 부캐 트럭 + 기사 고용: 수익의 80%만 들어옴, 부캐는 17강까지만
2. 튜닝(큐브식): 옵션 굴리기, 등급 일반 → 레어 → 에픽 → 전설
3. 지역 확장 = 회사 규모: 동네 → 옆 동네 → 도시 → 광역권 → 주 → 전국.
   넓히면 트럭 최대 대수, 배송 단가, 새 콘텐츠가 같이 열림. 조건은 돈(영업 허가비)
4. 돈 수급처: 주소 불명 택배(뽑기), 극한 배송(빡센 지형, 본캐 강수 필요),
   틀린 주소 찾기(힌트 미니게임), 주간 퀘스트, 급행 전화(선택형 도박)
5. 동선 짜기: 유저가 배송 순서를 짜서 더 빨리 돌게
6. 튜닝 데이: 매주 하루 (퍼짐 확률 감소 / 비용 할인 / 튜닝 등급업 2배 돌아가며)
7. 취업 단계(회사 트럭으로 시작하는 튜토리얼)
8. 스팀 연동: 업적(강수별), 스팀 서버 시간으로 시계 조작 막기, 저장 파일 간단 잠금
9. 랭킹(월간 수익 등): 넣으려면 강화 굴리기를 서버로 옮겨야 함
10. 전체 화면 프로그램 켜지면 자동으로 숨기기
11. 진짜 그림(픽셀아트), 소리
