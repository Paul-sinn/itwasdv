# 이미 정한 것 / 나중에 할 것

시제품 v0에서는 아래 어느 것도 만들지 않는다. 방향만 적어둔 문서.

## 이미 정한 것
- 스팀 유료 게임, 한 번 구매. 게임 안 결제(돈으로 재화 사기) 없음
- 작업표시줄 위 띠에 사는 데스크톱 방치형, 테마는 택배
- 엔진 강화: 최대 30강, 실패하면 유지, 18강부터 퍼짐. 30강은 사실상 로또
- 퍼지면 15강 고장 엔진 + 운행 정지, 스페어 엔진으로 수리
- 확률은 게임 안에서 전부 공개
- 스팀 장터에서 아이템 사고팔기는 넣지 않음 (봇 몰림)
- 숫자는 `data/balance.json` 하나에. 시뮬(`tools/delivery_sim.py`)과 게임이 같이 읽음
- 20강부터 시간당 수익이 1강마다 1.3배로 확 오름 (19강까지 1.1배). 강화 비용은 계속 "그 강수 수익의 N시간치"
  (2026-11-10 사용자. 시뮬 30일: 22강 찍는 유저 2.8% → 7.0%, 접는 유저 1.3% → 1.5%)
- 스페어 엔진은 강수와 상관없이 고정 50,000원 (2026-11-10 사용자. 전에는 퍼지기 직전 강수 수익 24시간치)
- 화면은 두 개 (2026-11-10, v0 플레이 테스트 뒤 사용자. 참고: Cast n Chill의 화면 구조)
  - 작은 화면(평소): 작업표시줄 쪽에서 백그라운드처럼 돌아감. 화면 가로 전체 띠가 아니라
    오른쪽 아래 구석에 꼬불꼬불한 길 하나 + 집들. 트럭이 집마다 1~2초 들렀다가 다음 집으로 → 반복.
    가로 띠보다 덜 거슬리게
  - 전체 화면: 작업표시줄 쪽에서 들어감. 옵션·기능이 더 많음: NPC와 상호작용, 회사 짓기,
    큐브(튜닝), 더 멋진 강화 화면

## 나중에 할 것 (대략 순서대로)
1. 부캐 트럭 + 기사 고용: 수익의 80%만 들어옴, 부캐는 17강까지만
2. 튜닝(큐브식): 옵션 굴리기, 등급 일반 → 레어 → 에픽 → 전설
3. 지역 확장 = 회사 규모: 동네 → 옆 동네 → 도시 → 광역권 → 주 → 전국.
   넓히면 트럭 최대 대수, 배송 단가, 새 콘텐츠가 같이 열림. 조건은 돈(영업 허가비)
4. 돈 수급처: 주소 불명 택배(뽑기), 극한 배송(빡센 지형, 본캐 강수 필요),
   틀린 주소 찾기(힌트 미니게임), 주간 퀘스트, 급행 전화(선택형 도박)
5. 동선 짜기: 유저가 배송 순서를 짜서 더 빨리 돌게
6. 튜닝 데이: 매주 하루 (퍼짐 확률 감소 / 비용 할인 / 튜닝 등급업 2배 돌아가며)
7. 취업 단계(회사 트럭으로 시작하는 튜토리얼)
8. 스팀 연동: 업적(강수별), 스팀 서버 시간으로 시계 조작 막기, 저장 파일 간단 잠금
9. 랭킹(월간 수익 등): 넣으려면 강화 굴리기를 서버로 옮겨야 함
10. 전체 화면 프로그램 켜지면 자동으로 숨기기
11. 진짜 그림(픽셀아트), 소리

## 떠오른 아이디어 (작업 중 생기면 아래에 한 줄씩)
- [정함 2026-11-10] 퍼졌을 때 스페어값이 없어서 수익 0으로 갇히는 문제 → 퍼질 수 있는 강수에서는
  강화 비용 + 스페어값이 있어야 강화 가능, 모자라면 "강화 비용 부족" (시제품에 넣음).
  시뮬(`tools/delivery_sim.py`)은 아직 유저의 60%(`CAREFUL_SHARE`)만 스페어값을 남긴다고 가정함.
  본게임도 이 규칙이면 시뮬을 100%로 맞추고, 스페어·보호 아이템이 있을 때는 남길 필요 없게 할지 정해야 함

## 시제품 v0 플레이 테스트 결과 (2026-11-10, 사용자)
1. 강화 누를 때 두근거림: 예 ("강화할 때 엄청 재밌음")
2. 18강 넘어서 겁남: 아직 덜 무서움 (안 퍼져봐서. 한 번 퍼지면 무서울 것 같다고 함)
3. 돈 모일 때까지 기다렸다 다시 누르고 싶음: 예
4. 켜둔 채 다른 일 할 때 안 거슬림: 아니오. 좀 거슬림, 생각했던 구조랑 다른 UI → 어떤 구조인지 듣고 정할 것
5. 퍼졌을 때 스페어 사서 다시 함: 예 (어쩔 수 없으니까)
- 사용자 의견: 강화 말고도 시간당 수익을 올릴 방법이 다양했으면 좋겠음 → 튜닝(큐브)을 넣고 싶음 (위 "나중에 할 것" 2번)

## v1 작업 중 떠오른 것 (2026-11-10, 에이전트 보고서. 만들지 않음)
- 길을 고리 모양으로: 돌아오는 길에도 다른 집들을 지나가서 볼거리가 늘어남 (지금은 집5에서 같은 길로 돌아옴)
- 큰 화면 차고에 "지금 돈"을 크게 (지금은 동네 왼쪽 위 구석에만)
- 화면 배율(125%·150%) 모니터에서는 작은 화면이 작아 보일 수 있음 → 배율 따라 키우기
- 창 모드 큰 화면 X 버튼 → 끝내기 대신 작은 화면으로 (끝내기는 알림 영역 메뉴에서)
- 큰 화면에서 다른 창으로 가면(Alt+Tab) 저절로 작은 화면으로 (지금은 큰 화면이 뒤에 남고 구석 작은 화면은 안 보임)
- 작은 화면을 눌러도 쓰던 프로그램의 입력 포커스를 안 뺏기
- 알림 영역 메뉴에 지금 화면 표시(체크)
- 창 모드 크기·위치를 settings.cfg에 저장해서 다음 실행에도
- 0강 "+금액"이 "+0.7" 같은 소수로 보임 (10원 미만만). 싫으면 `Fmt.payout`만 고치면 됨
