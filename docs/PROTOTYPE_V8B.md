# 시제품 v8b 지시서: 설정

> 2026-11-14. 기획서 10장 14번, 15.3(항상 위), 15.9(설정: 띠 크기·배율, 모니터 선택, 투명도, 항상 위, 알림, 언어, 숫자 표기) [확정].
> 계산 코드(`scripts/core`)와 `data/balance.json`은 안 바뀐다. 화면 담당 혼자 한다.
> 뺀 것: **소리 칸**(음원 없음, Q29), **전체화면 앱·게임이 켜지면 자동 숨기기**(Windows 창 감시가 필요 → `docs/IDEAS.md`), 스팀.
> 앞 단계: v8a (`prototype-v8a`). 합치는 곳은 `itwasdv-merge`(가지 `prototype-v8b`). **`itwasdv` 폴더는 건드리지 않는다.**

## 이 시제품으로 알아낼 것 (딱 하나)

**일하면서 켜 두기에 띠가 거슬릴 때, 설정에서 바로 고칠 수 있는가? (크기·투명도·자리·알림)**

## 정한 것

| 설정 | 고르는 값 (기본) | 적용 | 저장 |
|---|---|---|---|
| 언어 | 한국어 / English (**기본 = PC 언어**. 한국어가 아니면 English) | 바로. 열려 있는 화면 글자도 다시 그림 | `settings.cfg [ui] locale` |
| 숫자 표기 | 언어 따라 (기본) / 만·억 / K·M | 바로 | `[ui] number_style` |
| 알림 | 켜기 (기본) / 끄기. 끄면 동네 알림 글(할 일 끝, 업적, 방문 등)이 안 뜸. 편지봉투·전화 아이콘과 "+돈"은 그대로 | 바로 | `[ui] notices` |
| 급송 요청 전화 | (지금 그대로: 게임 저장 `rush_enabled`) | | |
| 큰 화면 방식 | (지금 그대로: 전체 화면 / 창 모드) | | |
| 항상 위 | 켜기 (기본) / 끄기. 작은 화면(띠)만 | 바로 | `[strip] always_on_top` |
| 띠 투명도 | 100% (기본) / 85% / 70% / 50%. 작은 화면만 (큰 화면은 늘 100%) | 바로 | `[strip] opacity` |
| 띠 크기 | 100% (기본) / 125% / 150%. 띠 창과 안의 그림·글자를 같이 키움. 클릭 받는 곳(`visible_rects`)도 같이 | 바로 | `[strip] scale` |
| 띠 자리 | 오른쪽 아래 (기본) / 왼쪽 아래 (작업표시줄 바로 위) | 바로 | `[strip] corner` |
| 모니터 | 주 모니터 (기본) / 모니터 1, 2, … (연결된 수만큼). 고른 모니터가 뽑히면 주 모니터로 돌아가고 설정값은 남김 | 바로. 큰 화면도 그 모니터에 | `[strip] screen` |

- 설정 화면은 지금 [설정] 창을 넓혀 세 묶음: **게임**(언어, 숫자 표기, 알림, 급송 전화) / **띠**(항상 위, 투명도, 크기, 자리, 모니터) / **큰 화면**(전체 화면·창 모드). [기본값으로] 버튼 하나 (게임 저장은 안 건드림)
- 설정 파일은 지금 `settings.cfg` (`ScreenMode.settings_path`). 게임 저장과 따로라 저장을 지워도 남음
- 틀린 값(손으로 고친 파일)은 기본값으로 읽음
- 창 자리·크기 계산은 **화면 없이 시험할 수 있는 순수 함수**로 (`DesktopWindow`에 모니터 사각형·작업 영역·배율·자리를 넣으면 띠 사각형을 돌려주는 함수). 진짜 창에 적용하는 줄은 얇게

## 코드 약속

- 계산 쪽 약속 변경 없음
- 화면 안에서: `scripts/ui/prefs.gd` (새) 한 곳이 설정을 읽고 쓰고 기본값·틀린 값 처리를 맡는다. 다른 화면 코드는 `Prefs.get_…` / `Prefs.set_…`만 부른다 (ConfigFile을 직접 열지 않는다. `ScreenMode`의 지금 읽기·쓰기는 그대로 써도 됨)
- 숫자 표기는 `Fmt` 한 곳에서 (지금 언어로 고르는 자리를 `Prefs` 값으로)

## 화면 없는 확인 (`tests/check_v8b.gd`, 새)

① 설정 창 세 묶음·버튼이 ko·en 5가지 창 크기에서 창 안 ② 언어를 바꾸면 열려 있는 화면(동네 구석 줄, 튜닝숍, 물류센터, 설정 창) 글자가 바로 바뀌고 다시 켜도 유지 ③ 숫자 표기 3가지 ("1.2만" / "12K") ④ 알림 끄면 알림 글이 안 뜨고 아이콘·"+돈"은 뜸 ⑤ 띠 사각형 순수 함수: 크기 3가지 × 자리 2가지 × 모니터 2개(배치가 다른 가짜 사각형)에서 작업 영역 안·작업표시줄 위·구석에 붙음 ⑥ 띠 크기를 바꿔도 `visible_rects()`가 창 안이고 건물 클릭 자리가 그림과 맞음 ⑦ 뽑힌 모니터 번호 → 주 모니터 ⑧ 틀린 설정값 → 기본값 ⑨ [기본값으로] ⑩ 기존 확인 전부 통과 (기본값에서는 지금과 똑같이 보임)
